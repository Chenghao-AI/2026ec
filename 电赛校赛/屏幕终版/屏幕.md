# STM32F407ZET6 + 3.5寸 SPI 屏第二阶段保底方案（横屏 + 触屏版）

## 1. 硬件物理接线表（更新版）

由于 CLK 更改为 **`PB3`** [1]，请严格按照下表连接杜邦线。

> ⚠️ **供电安全提示**：由于屏幕板载 3.3V LDO 降压芯片（U2），将屏幕 **VCC 直接接开发板的 5.0V**，降压后供给屏幕的电压最为稳定。若接 3.3V，可能会因降压压差导致屏幕白屏或显示暗淡。

| 屏幕引脚丝印 | 开发板引脚 | 引脚功能分类   | CubeMX 引脚模式配置    | 核心调试说明                                   |
| :----------- | :--------- | :------------- | :--------------------- | :--------------------------------------------- |
| **GND**      | **GND**    | 共地           | 无                     | 必须共地                                       |
| **VCC**      | **5V**     | 逻辑供电       | 无                     | **接 5V 保证板载 LDO 输出足额 3.3V**           |
| **CLK**      | **PB3**    | 硬件 SPI1_SCK  | `SPI1_SCK`             | **【更新】显示与触摸共用时钟线** [1]           |
| **MOS**      | **PA7**    | 硬件 SPI1_MOSI | `SPI1_MOSI`            | **【共用总线】**显示与触摸共用数据写入线       |

## 2. STM32CubeMX 详细配置流程

### 2.1 启用 SWD 调试（解除 `PB3` 引脚占用）
在 STM32 中，`PB3` 默认作为 JTAG 调试的 `JTDO` 引脚。要想让它作为普通的 `SPI1_SCK` 硬件引脚，必须在 CubeMX 中将调试模式限制为 SWD（Serial Wire）：
1. 在左侧菜单栏，点击 **System Core** -> **SYS**。
2. 将 **Debug** 选项下拉修改为 **`Serial Wire`**。
   *(此时引脚图上的 PA13 (SWDIO) 和 PA14 (SWCLK) 会变绿，而 PB3 将被顺利释放出来供我们使用)*

### 2.2 开启外部时钟源
1. 点击左侧 **System Core** -> **RCC**。
2. 将 **High Speed Clock (HSE)** 修改为 **`Crystal/Ceramic Resonator`**。

### 2.3 硬件 SPI1 的重新映射 [1]
1. 点击左侧 **Connectivity** -> **SPI1**。
2. 将 **Mode** 选为 **`Full Duplex Master`**（全双工主机）。
3. **关键引脚重映射操作** [1]：
   * 软件默认可能会将 `SPI1_SCK` 分配给 `PA5`。
   * 请在右侧的芯片物理引脚图上找到 **`PB3`**，左键点击它，在弹出的功能列表中选择 **`SPI1_SCK`**。
   * 此时 `SPI1_SCK` 将自动从 `PA5` 转移到 `PB3` [1]。
4. **参数配置（Parameter Settings）**：
   * `Frame Format`: `Motorola`
   * `Data Size`: `8 Bits`
   * `First Bit`: `MSB First`
   * `CPOL` / `CPHA`: 选择 **`Low`** / **`1 Edge`**（即标准 SPI Mode 0，对 ST7796 与 XPT2046 均最稳妥）。
   * `NSS`: `Software`。
   * `Prescaler`: 选中 **`16`**（在 APB2 为 84MHz 时，输出速率为 **`5.25 MBits/s`**，既能兼顾触摸的稳定，也能提供流畅的屏幕刷新率）。

### 2.4 GPIO 引脚定义
在引脚图上依次左键点击以下引脚并配置：
* **`PB12`** (`LCD_CS`) / **`PB13`** (`LCD_DC`) / **`PB14`** (`LCD_RES`) / **`PC4`** (`TP_CS`)：
  * 设为 **`GPIO_Output`**（推挽输出、无上下拉、High 速度、初始电平设为 **`High`**）。
* **`PB15`** (`LCD_BLK`)：
  * 设为 **`GPIO_Output`**（推挽输出、无上下拉、High 速度、初始电平设为 **`Low`**）。
* **`PC5`** (`TP_PEN`)：
  * 设为 **`GPIO_Input`**，且在下面的参数中务必将 `Pull-up/Pull-down` 修改为 **`Pull-up`**（内部上拉）。

### 2.5 168MHz 时钟树配置
切换到 **Clock Configuration** 页面：
1. 最左侧 `HSE Input frequency` 填：**`8`**。
2. `PLL Source Mux` 选中 **`HSE`**。
3. `Main PLL` 参数手动配置为：`/M` = **`8`**，`*N` = **`336`**，`/P` = **`2`**，`/Q` = **`4`**（`/Q` 变灰无法编辑，直接无视即可）。
4. `System Clock Mux` 选中 **`PLLCLK`**。
5. `AHB Prescaler` 选 **`/1`**（`HCLK` 达到 168MHz）。
6. `APB1 Prescaler` 选 **`/4`**（`PCLK1` 自动计算为 42MHz，硬件最大上限）。
7. `APB2 Prescaler` 选 **`/2`**（`PCLK2` 自动计算为 84MHz，硬件最大上限）。

### 2.6 生成 Keil 代码
* 点击 `Project Manager` -> `Code Generator`，勾选 **`Generate peripheral initialization as a pair of '.c/.h' files`**。
* 点击右上角 **`GENERATE CODE`**。

### 3.2 屏幕横屏驱动源文件 `lcd_st7796.c` [17.1]
在工程中新建该文件并保存至 `Core/Src`：
```c
#include "lcd_st7796.h"
#include "spi.h"

#define LCD_CS_LOW()     HAL_GPIO_WritePin(GPIOB, GPIO_PIN_12, GPIO_PIN_RESET)
#define LCD_CS_HIGH()    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_12, GPIO_PIN_SET)

#define LCD_DC_CMD()     HAL_GPIO_WritePin(GPIOB, GPIO_PIN_13, GPIO_PIN_RESET)
#define LCD_DC_DATA()    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_13, GPIO_PIN_SET)

#define LCD_RES_LOW()    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_14, GPIO_PIN_RESET)
#define LCD_RES_HIGH()   HAL_GPIO_WritePin(GPIOB, GPIO_PIN_14, GPIO_PIN_SET)

#define LCD_BLK_HIGH()   HAL_GPIO_WritePin(GPIOB, GPIO_PIN_15, GPIO_PIN_SET)

static void SPI_WriteByte(uint8_t data) {
    HAL_SPI_Transmit(&hspi1, &data, 1, 1000);
}

static void LCD_WriteCommand(uint8_t cmd) {
    LCD_DC_CMD(); LCD_CS_LOW(); SPI_WriteByte(cmd); LCD_CS_HIGH();
}

static void LCD_WriteData8(uint8_t data) {
    LCD_DC_DATA(); LCD_CS_LOW(); SPI_WriteByte(data); LCD_CS_HIGH();
}

static void LCD_WriteData16(uint16_t data) {
    uint8_t temp[2];
    temp[0] = data >> 8; temp[1] = data & 0xFF;
    LCD_DC_DATA(); LCD_CS_LOW(); HAL_SPI_Transmit(&hspi1, temp, 2, 1000); LCD_CS_HIGH();
}

void LCD_Reset(void) {
    LCD_RES_HIGH(); HAL_Delay(10);
    LCD_RES_LOW();  HAL_Delay(20);
    LCD_RES_HIGH(); HAL_Delay(150);
}

void LCD_SetAddressWindow(uint16_t x1, uint16_t y1, uint16_t x2, uint16_t y2) {
    LCD_WriteCommand(0x2A); LCD_WriteData16(x1); LCD_WriteData16(x2);
    LCD_WriteCommand(0x2B); LCD_WriteData16(y1); LCD_WriteData16(y2);
    LCD_WriteCommand(0x2C);
}

void ST7796_Init(void) {
    LCD_Reset();
    
    // 命令解锁
    LCD_WriteCommand(0xF0); LCD_WriteData8(0xC3);
    LCD_WriteCommand(0xF0); LCD_WriteData8(0x96);
    
    // MADCTL (0x36) 配置为横屏扫描模式 (BGR 颜色顺序) [17.1]
    // 若显示出现左右镜像，可将 0xEC 尝试修改为 0x2C
    LCD_WriteCommand(0x36); LCD_WriteData8(0xEC); 
    
    // 像素格式 (RGB565)
    LCD_WriteCommand(0x3A); LCD_WriteData8(0x05);
    
    // 反色、帧率、驱动控制参数
    LCD_WriteCommand(0xB4); LCD_WriteData8(0x01);
    LCD_WriteCommand(0xB6); LCD_WriteData8(0x20); LCD_WriteData8(0x02);
    LCD_WriteCommand(0xB5); LCD_WriteData8(0x02); LCD_WriteData8(0x03); LCD_WriteData8(0x00); LCD_WriteData8(0x04);
    LCD_WriteCommand(0xB1); LCD_WriteData8(0x80); LCD_WriteData8(0x10);
    LCD_WriteCommand(0xB7); LCD_WriteData8(0xC6);
    LCD_WriteCommand(0xC5); LCD_WriteData8(0x24);
    LCD_WriteCommand(0xE4); LCD_WriteData8(0x31);
    LCD_WriteCommand(0xE8);
    LCD_WriteData8(0x40); LCD_WriteData8(0x8A); LCD_WriteData8(0x00); LCD_WriteData8(0x00);
    LCD_WriteData8(0x29); LCD_WriteData8(0x19); LCD_WriteData8(0xA5); LCD_WriteData8(0x33);
    
    // 伽马配置
    LCD_WriteCommand(0xE0);
    LCD_WriteData8(0xF0); LCD_WriteData8(0x09); LCD_WriteData8(0x13); LCD_WriteData8(0x12); LCD_WriteData8(0x12);
    LCD_WriteData8(0x2B); LCD_WriteData8(0x3C); LCD_WriteData8(0x44); LCD_WriteData8(0x4B); LCD_WriteData8(0x1B);
    LCD_WriteData8(0x18); LCD_WriteData8(0x17); LCD_WriteData8(0x1D); LCD_WriteData8(0x21);
    
    LCD_WriteCommand(0xE1);
    LCD_WriteData8(0xF0); LCD_WriteData8(0x09); LCD_WriteData8(0x13); LCD_WriteData8(0x0C); LCD_WriteData8(0x0D);
    LCD_WriteData8(0x27); LCD_WriteData8(0x3B); LCD_WriteData8(0x44); LCD_WriteData8(0x4D); LCD_WriteData8(0x0B);
    LCD_WriteData8(0x17); LCD_WriteData8(0x17); LCD_WriteData8(0x1D); LCD_WriteData8(0x21);
    
    LCD_WriteCommand(0xF0); LCD_WriteData8(0xC3);
    LCD_WriteCommand(0xF0); LCD_WriteData8(0x69);
    
    LCD_WriteCommand(0x13); HAL_Delay(20);
    LCD_WriteCommand(0x11); HAL_Delay(120);
    LCD_WriteCommand(0x29); HAL_Delay(20);
    
    LCD_BLK_HIGH(); // 点亮背光
}

void LCD_Fill(uint16_t x_start, uint16_t y_start, uint16_t x_end, uint16_t y_end, uint16_t color) {
    uint32_t size = (x_end - x_start + 1) * (y_end - y_start + 1);
    LCD_SetAddressWindow(x_start, y_start, x_end, y_end);
    LCD_DC_DATA(); LCD_CS_LOW();
    
    #define CHUNK_SIZE 256
    uint8_t chunk_buf[CHUNK_SIZE * 2];
    for (uint16_t i = 0; i < CHUNK_SIZE; i++) {
        chunk_buf[2 * i] = color >> 8; chunk_buf[2 * i + 1] = color & 0xFF;
    }
    uint32_t full_chunks = size / CHUNK_SIZE;
    uint32_t rem_pixels = size % CHUNK_SIZE;
    for (uint32_t i = 0; i < full_chunks; i++) {
        HAL_SPI_Transmit(&hspi1, chunk_buf, CHUNK_SIZE * 2, 1000);
    }
    if (rem_pixels > 0) {
        HAL_SPI_Transmit(&hspi1, chunk_buf, rem_pixels * 2, 1000);
    }
    LCD_CS_HIGH();
}

void LCD_Clear(uint16_t color) {
    LCD_Fill(0, 0, LCD_WIDTH - 1, LCD_HEIGHT - 1, color);
}

// 触摸画点：为了让手势点看起来更清晰，这里绘制一个 3x3 的实心笔刷点
void LCD_DrawPoint(uint16_t x, uint16_t y, uint16_t color) {
    if (x >= LCD_WIDTH || y >= LCD_HEIGHT) return;
    LCD_Fill(x - 1, y - 1, x + 1, y + 1, color);
}
```

### 3.3 触摸屏驱动头文件 `xpt2046.h` [21]

```c
#ifndef __XPT2046_H
#define __XPT2046_H

#include "main.h"

// XPT2046 读取指令
#define CMD_READ_X  0xD0  // 读 X 通道坐标 (12位，差分模式) [22]
#define CMD_READ_Y  0x90  // 读 Y 通道坐标 (12位，差分模式) [22]

// 电阻触摸屏的标准初始标定范围
#define TP_MIN_X    350
#define TP_MAX_X    3800
#define TP_MIN_Y    250
#define TP_MAX_Y    3850

uint8_t TP_IsPressed(void);
uint8_t TP_Read_Coordinates(uint16_t *x, uint16_t *y);
```

### 3.4 触摸屏驱动源文件 `xpt2046.c` [21]
在工程中新建该文件并保存至 `Core/Src`：
```c
#include "xpt2046.h"
#include "spi.h"
#include "lcd_st7796.h"

#define TP_CS_LOW()      HAL_GPIO_WritePin(GPIOC, GPIO_PIN_4, GPIO_PIN_RESET)
#define TP_CS_HIGH()     HAL_GPIO_WritePin(GPIOC, GPIO_PIN_4, GPIO_PIN_SET)

// 通过读取 PEN（PC5）引脚电平检测是否被按下 [20.1]
uint8_t TP_IsPressed(void) {
    if (HAL_GPIO_ReadPin(GPIOC, GPIO_PIN_5) == GPIO_PIN_RESET) {
        return 1; // 处于低电平，代表有按下
    }
    return 0; // 高电平，无触摸
}

// 读取 XPT2046 物理 ADC 采样值
static uint16_t XPT2046_Read_ADC(uint8_t cmd) {
    uint8_t tx_data[3] = {cmd, 0x00, 0x00};
    uint8_t rx_data[3] = {0};
    
    TP_CS_LOW();
    // 共享主 SPI1 发送命令并读取 12 位 ADC 值 [22]
    HAL_SPI_TransmitReceive(&hspi1, tx_data, rx_data, 3, 1000);
    TP_CS_HIGH();
    
    uint16_t adc_val = ((rx_data[1] << 8) | rx_data[2]) >> 3;
    return adc_val & 0x0FFF;
}

// 触摸读取与滤波函数 [23]
uint8_t TP_Read_Coordinates(uint16_t *x, uint16_t *y) {
    uint16_t raw_x_arr[5], raw_y_arr[5];
    uint32_t sum_x = 0, sum_y = 0;
    
    // 连续采集 5 次数据进行平均滑动滤波，消除触点电阻抖动 [23]
    for (uint8_t i = 0; i < 5; i++) {
        raw_x_arr[i] = XPT2046_Read_ADC(CMD_READ_X);
        raw_y_arr[i] = XPT2046_Read_ADC(CMD_READ_Y);
        sum_x += raw_x_arr[i];
        sum_y += raw_y_arr[i];
    }
    
    uint16_t avg_x = sum_x / 5;
    uint16_t avg_y = sum_y / 5;
    
    // 限制在有效电阻标定范围内
    if (avg_x < TP_MIN_X) avg_x = TP_MIN_X;
    if (avg_x > TP_MAX_X) avg_x = TP_MAX_X;
    if (avg_y < TP_MIN_Y) avg_y = TP_MIN_Y;
    if (avg_y > TP_MAX_Y) avg_y = TP_MAX_Y;
    
    // 将电阻阻值转换为横屏 [0-479, 0-319] 像素坐标 [24]
    uint16_t map_x = (avg_x - TP_MIN_X) * LCD_WIDTH / (TP_MAX_X - TP_MIN_X);
    uint16_t map_y = (avg_y - TP_MIN_Y) * LCD_HEIGHT / (TP_MAX_Y - TP_MIN_Y);
    
    // 🚨 【轴向方向修正（极重要）】 [24]：
    // 电阻屏的贴合方向可能存在镜像，如果您在屏上画点时，发现画笔运动方向和手指相反：
    // 1. 如果左右镜像了，请取消下面这行注释：
    // map_x = (LCD_WIDTH - 1) - map_x;
    // 2. 如果上下颠倒了，请取消下面这行注释：
    // map_y = (LCD_HEIGHT - 1) - map_y;
    
    *x = map_x;
    *y = map_y;
    
    return 1;
}
```

### 3.5 应用程序主循环 `main.c` [23]
在生成出的 `main.c` 中添加对驱动的调用：
```c
/* USER CODE BEGIN Includes */
#include "lcd_st7796.h"
#include "xpt2046.h"
/* USER CODE END Includes */

// ... 省略底层外设初始化 ...

int main(void)
{
  HAL_Init();
  SystemClock_Config();
  MX_GPIO_Init();
  MX_SPI1_Init();

  /* USER CODE BEGIN 2 */
  // 第一步强行关触摸芯片，避免其干扰 SPI1 初始化
  HAL_GPIO_WritePin(GPIOC, GPIO_PIN_4, GPIO_PIN_SET); 
  HAL_GPIO_WritePin(GPIOB, GPIO_PIN_15, GPIO_PIN_RESET);
  
  // 初始化屏幕（480x320 横屏） [17.1]
  ST7796_Init();
  
  // 填充屏幕底色为纯黑色
  LCD_Clear(BLACK);
  
  uint16_t touch_x = 0;
  uint16_t touch_y = 0;
  /* USER CODE END 2 */

  /* Infinite loop */
  /* USER CODE BEGIN WHILE */
  while (1)
  {
    // 轮询检测是否被按下 [23]
    if (TP_IsPressed()) 
    {
        // 读取滤波转换后的屏幕坐标 [23]
        if (TP_Read_Coordinates(&touch_x, &touch_y)) 
        {
            // 在对应按下的地方绘制一个黄色的实心画笔点
            LCD_DrawPoint(touch_x, touch_y, YELLOW);
        }
    }
    HAL_Delay(5); // 适度延时防抖
    /* USER CODE END WHILE */

    /* USER CODE BEGIN 3 */
  }
  /* USER CODE END 3 */
}
```

## 4. 第二阶段调试标准与现象 [26]

* **屏幕底色**：烧录运行后，屏幕背光正常点亮，全屏呈纯黑色。
* **笔迹跟手**：用手指或塑料笔尖滑过屏幕，屏幕上会流畅、跟手地画出黄色线条 [26]。
* **轴向修正**：
  * **故障 1（左右反了）**：请在 `xpt2046.c` 第 50 行取消 `map_x = (LCD_WIDTH - 1) - map_x;` 的注释 [24]。
  * **故障 2（上下反了）**：请在 `xpt2046.c` 第 53 行取消 `map_y = (LCD_HEIGHT - 1) - map_y;` 的注释 [24]。
