| 板上 33Ω 串联排阻                       | J10 / J11 所有 IO 与 FPGA 之间都有 33Ω，保护外部过压/过流，并帮 ACLK 走线做阻尼。 |

### WSL 调起 Windows 程序的 4 个细节

1. **必须用 `cmd.exe /c "..."`**，不能直接 `/mnt/c/.../vivado.bat`——后者会因 Windows 端的 `$PATH` 缺失、绝对路径里有空格、UNC 路径限制而失败。已验证：

   # → Vivado v2019.1 (64-bit)  SW Build 2552052 on Fri May 24 14:49:42 MDT 2019
   ```

2. **路径里有中文 / 空格** 没问题，但**不能**用 UNC（`\\wsl.localhost\...`）当工作目录——`cmd.exe` 不接受。建议：工作目录放在 `/mnt/c/Users/.../FPGA练习_windows端/Vivado/prj_xxx`，这是真实 Windows 路径。

## 仪器支持

### 第一种：RIGOL DP832 可编程直流电源 (Programmable DC Power Supply)

####  作用介绍
可编程直流电源用于为待测电路或电子设备（DUT）提供稳定、可调的直流电（电压和电流）。
* **多通道输出**：该型号（DP832）拥有三个独立的输出通道（通道1和2为 30V/3A，通道3为 5V/3A）。
* **保护功能**：支持过压保护（OVP）和过流保护（OCP），能有效防止因操作失误或电路短路而烧毁待测板。
* **可编程性**：可以通过设置定时任务让其按特定波形或规律输出电压。

#### 使用方式
1. **连接导线**：将香蕉头测试线连接到对应的输出端子上（红色为正极 `+`，黑色为负极 `-`，绿色/黑色带接地标志的为接地端 `GND`）。
2. **开机并选择通道**：按下左下角的电源开关启动。接着按下前面板上的通道选择按键（`1`、`2` 或 `3`）来点亮想要操作的通道。
3. **设定参数**：
   * 按下参数微调键或使用数字键盘输入目标电压（V）和限制电流（I）。
   * 旋转右侧的物理大旋钮可以实现参数的连续微调。
4. **使能输出**：确认接线无误且参数设置合理后，按下对应通道上方的 `On/Off` 键，或按下 `All On/Off` 键开启输出，电源开始供电。

### 第二种：RIGOL DS2302A 数字示波器 (Digital Oscilloscope)

#### 作用介绍
示波器被称为电子工程师的“眼睛”，用于将肉眼看不见的电信号转换成随时间变化的动态波形，并在屏幕上显示出来。
* **信号分析**：可精确测量信号的幅值（峰峰值、均方根）、频率、周期、上升/下降时间等物理参数。
* **故障诊断**：用来观察电路中的噪声、毛刺、信号畸变等异常情况。

#### 使用方式
1. **连接探头**：将示波器探头连接到通道输入端（如 `CH1` 或 `CH2`）。将探头的接地夹连接到待测电路的参考地（GND），探针接触需要检测的信号点。
2. **探头补偿（建议首用）**：将探头挂在示波器右下角的“补偿信号输出端”（通常是 1kHz 的方波信号），若屏幕上的方波有圆角或过冲，用小螺丝刀微调探头上的补偿电容，使其呈现标准方波。
3. **波形捕捉与调整**：
   * 接通电路信号后，可先按下右上角的 `AUTO`（自动设置）键，示波器会自动调整至合适的量程显示波形。
   * 手动调节时，使用 **VERTICAL（垂直）** 区域的旋钮调节电压灵敏度（波形高矮），使用 **HORIZONTAL（水平）** 区域的旋钮调节时基（波形宽窄）。
4. **触发设置**：调节 **TRIGGER（触发）** 区域的 `LEVEL` 旋钮，将触发电平线移至波形高度范围内，使不稳定的波形静止锁在屏幕上。
5. **参数读取**：按下 `Measure`（测量）按键，在屏幕上调出自动测量菜单，读取频率、电压等数值。

### 第三种：RIGOL DM858 数字万用表 (Digital Multimeter)

#### 作用介绍
数字万用表是用于高精度测量各种电学基本参数的仪器。这款 DM858 是一台 5½ 位（五位半）精度的台式万用表。
* **多功能测量**：可测量直流/交流电压（V）、直流/交流电流（I）、电阻（二线/四线法）、电容、频率、周期、温度。
* **通路/二极管测试**：内置蜂鸣器用于检测导线是否通畅，以及测量二极管的正向导通压降。

#### 使用方式
1. **插入表笔**：
   * 将黑色表笔插入 `LO`（公共负端）插孔。
   * 根据测量项目插入红色表笔：测量电压、电阻、电容、频率时插入右侧 `Input` 插孔；测量电流时根据电流大小插入左侧的 `10A` 或 `I Fuse` 插孔。
2. **选择测量功能**：在右侧控制面板中按下对应的测量功能键，例如：
   * `～ V`（交流电压）、`- V`（直流电压）
   * `Ω 2W`（两线制电阻测量）
   * `▶|`（二极管测试）或 `•))``（通路测试）
3. **设置量程**：默认通常为 `Auto`（自动量程），仪器会自动切换到最合适的量程。也可以通过方向键手动选择固定量程以提高测量速度。
4. **接触测量与读数**：将表笔接触待测元件或节点，屏幕即会显示高精度的数值。

### 第四种：SIGLENT SDG 2122X 函数/任意波形发生器 (Function/Arbitrary Waveform Generator)

#### 作用介绍
波形发生器（信号源）是用于产生特定频率、幅值和波形的电信号仪器。
* **激励源**：它作为信号源输入到被测电路中（例如放大器、滤波器），配合示波器等仪器来观察电路的响应。
* **多种波形**：除了产生正弦波、方波、三角波、脉冲等标准波形外，还可以输出调幅/调频信号，或通过软件导入用户自定义的任意波形。

#### 使用方式
1. **连接输出**：使用 BNC 同轴电缆将仪器的输出通道（如 `CH1` 或 `CH2` 端口）连接到待测电路的输入端。
2. **选择基本波形**：按下屏幕下方的波形快捷键（例如正弦波 Sine、方波 Square、脉冲 Pulse 等）或通过 `Waveforms` 菜单选择目标波形。
3. **设置基本参数**：
   * 按下屏幕旁的参数软键，依次输入所需信号的 **Frequency（频率）**、**Amplitude（幅值/峰峰值）** 以及 **Offset（直流偏置）**。
   * 通过数字键盘输入数值，并配合右侧的单位按键（如 kHz、MHz、Vpp、mVpp 等）进行确认。
4. **使能输出**：参数设置完毕后，按下右下角通道对应的绿色 `Output` 按键（按键灯亮起），此时信号开始向外输出。

### 第五种：SIGLENT SSA 3015X Plus 频谱分析仪 (Spectrum Analyzer)

#### 作用介绍
频谱分析仪是从**频域**（频率-幅度关系）角度来分析电信号的仪器。
* **频域分析**：与示波器（时域）不同，频谱仪可以将信号中所有的频率成分平铺开来。
* **应用场景**：广泛用于无线电、射频（RF）电路调试、电磁干扰（EMI/EMC）测试、信号谐波失真分析以及滤波器频率响应测量（该型号带 TG 源，即可配合跟踪源进行双端口网络测量）。

#### 使用方式
1. **连接射频输入**：

   * 将带有射频同轴线缆（通常为 N 型转 BNC 或 SMA）的信号接入 `RF INPUT` 端口。
   * **安全警告**：射频输入端非常脆弱。**绝对不能输入超过其最大允许安全功率（通常为 +30 dBm，即 1W）的信号，亦不能输入直流高压**，否则会烧毁内部衰减器和混频器。如果不确定信号大小，必须在前端加装外部衰减器。

2. **设置扫描范围**：
   * 按下 `Frequency`（频率）键，设置感兴趣的中心频率（Center Freq）或起始/终止频率。
   * 按下 `Span`（扫宽）键，设置需要观察的频谱宽度。

3. **设置参考电平**：按下 `Amplitude`（幅度）键，调整参考电平（Ref Level），使屏幕上信号的最高峰落在一个便于观测的中间高度，同时避免内部混频器过载。

4. **调整分辨率带宽（可选）**：按下 `BW`（带宽）键，可以微调分辨率带宽（RBW）以分清靠得极近的两个信号，或微调视频带宽（VBW）以滤除屏幕上的草状噪声。

5. **标记测量**：按下 `Marker`（标记）键，在屏幕上产生一个光标，旋转右侧的大旋钮移动光标至目标信号峰值处，屏幕右上角会精确显示该信号点的频率和功率值（通常单位为 dBm）。

# 2023 年全国大学生电子设计大赛 D 题 —— 八步实现总纲

## 0. 总纲与共识（写在每一步前面）

### 0.1 设计目标回顾

* 输入：`u_M` 来自 SIGLENT SDG2122X 函数发生器 CH1，载波 `f_c = 2 MHz`，题目载波峰峰值原为 100 mV，**我们这里人为放大到 1 Vpp**（信号发生器端调幅即可，无需前置低噪放），波形种类包含 AM / FM / CW / 2ASK / 2FSK / 2PSK 六种。
* 装置：FPGA + 双通道 ADC（A9226）+ PL 4 颗 LED + 4 位带小数点数码管 + PL 4 个按键。
* 输出：J11 上仅1根公引脚中输出"模拟/数字解调信号 `u_o`"，**不经过 DAC**，题目调制频率 ≤ 10 kHz，远低于 LVCMOS33 的带宽能力。
* 反馈显示：PL LED[3:0] 表示调制类别（`000`=AM，`001`=FM，`010`=CW，`011`=ASK，`100`=FSK，`101`=PSK，**低电平点亮**）；4 位数码管显示关键参数，按 PL KEY1~KEY4 切换显示项。

## 步骤 1 —— 信道打通（让 ADC A 通道原始数据原样点亮 PL LED）

### 1.1 原理

* **目标**：证明 SIGLENT → BNC 同轴线 → ADC A 通道 → FPGA → PL LED 这条链路完整通畅；为后续 DSP 处理确认 `adc_a_data` 的直流偏置（约 `12'h800`）、峰峰值（≈ 1 V 满量程对应 ±2 V 输入下约 2000 LSB 摆幅）。
* **做法**：把 ADC A 通道 12 bit 数据的**高 4 位**直接接到 `pl_led[3:0]`（PL LED 低有效——所以位值要先取反才能保证"高电平熄灭、低电平点亮"符合肉眼直觉）。这样在示波器/肉眼层面就能看到 ADC 真实值在 16 个电平间跳变，信号发生器送一个 2 MHz CW，肉眼能看到 LED 在某个亮度闪烁。
* **关键设计**：MMCM 产生 40 MHz ADC 时钟，与 ADC 数据采样沿对齐（FPGA 在 ACK 上升沿采数据），用 `IDDR` 把单端 12 bit 数据同步到 `clk_40m` 域内。

### 1.2 连线（硬件）

| 源 | 目标 | 线材 / 接口 | 备注 |
| --- | --- | --- | --- |
| RIGOL DP832 CH1 (+5 V) | ADC 模块 VIN/VCC | 香蕉头→杜邦 | 给 ADC 板供电（板上 SGM2036-3.3 LDO 自行降到 3.3 V） |
| RIGOL DP832 CH2 (+5 V) | FPGA 板 USB/下载器 | USB | 给 Zynq PL 端逻辑供电 |
| SIGLENT SDG2122X CH1 | ADC A 通道单端输入 | BNC→SMA 同轴 | 信号发生器设置：Sine、2 MHz、**1 Vpp**、Offset 0 V、输出阻抗 50 Ω，Output ON |
| ADC ACLK 引脚 | FPGA P14 | **≤8 cm 直插杜邦**（重要！） | 板卡上 33 Ω 排阻帮忙阻尼 |
| ADC 模块 GND | FPGA 板 GND（任一 GND 测试环） | 短粗线 | 必须共地，否则 ADC 偏置会浮空 |

> B 通道悬空即可。

  }

## 步骤 2 —— 检测 AM 波（调幅系数 `m_a` + 调制频率 `F`）

### 2.1 原理

* **AM 信号数学模型**：`u_M(t) = A_c [1 + m_a·cos(2π F t)] · cos(2π f_c t)`，其中载波峰峰 1 V → `A_c = 0.5 V`；`0.3 < m_a < 1`；`F ∈ {1,2,3,4,5} kHz`。
* **正交下变频**：把 `x(n)` 乘 `cos(2π f_c n/fs)` 得 `I(n)`，乘 `sin(2π f_c n/fs)` 得 `Q(n)`，经 CIC + 补偿 FIR 降到 200 kHz。
  * I_base ≈ `0.5 A_c [1 + m_a·cos(2π F n/fs')]`
  * Q_base ≈ 0（理想情况）
* **包络检波**：`R(n) = sqrt(I² + Q²) ≈ 0.5 A_c [1 + m_a·cos(2π F n/fs')]`。CORDIC 算法实现（迭代 16 次）。
* **参数估计**：
  * `m_a = (R_max - R_min) / (R_max + R_min)`
  * `F` = 对 `R(n)` 做去直流后 1024 点 FFT（在 200 kHz 域，频率分辨率 ≈ 195 Hz，完全满足 50 Hz 误差要求）
* **判决依据（AM 的特征）**：
  * 包络 R 的 AC 含量 / DC 含量 > 0.25（说明调制度明显）
  * 瞬时频率 Δθ 的方差很小（说明频率基本不变）
  * 包络直方图是连续分布（单峰），不是 ASK 那种"两个分离团"

## 步骤 3 —— 检测 FM 波（调频系数 `m_f` + 最大频偏 `Δf_max` + 调制频率 `F`）

### 3.1 原理

* **FM 信号**：`u_M(t) = A_c · cos[ 2π f_c t + m_f · sin(2π F t) ]`，`1 ≤ m_f ≤ 5`，`F ∈ {1,2,3,4,5} kHz`。
* **最大频偏**：`Δf_max = m_f · F`。
* **正交下变频 → 鉴频**：
  * `I = R·cos(θ)`、`Q = R·sin(θ)`（CORDIC 输出已直接给 `θ`）。
  * 鉴频公式：`f_inst(n) = [θ(n) - θ(n-1)] / (2π · Δt)`，这里 `Δt = 1/200k = 5 µs`。为避免相位卷绕，要先做 `unwrap`：如果 `|Δθ| > π`，则 `Δθ -= sign(Δθ)·2π`。
  * `f_inst(n)` 即瞬时频率相对 f_c 的偏移（Hz）。把它的直流分量加回 `f_c = 2 MHz` 后再做 FFT 求 `F`；`Δf_max` 等于 `f_inst` 的最大绝对值。
* **判决依据（FM 的特征）**：
  * 包络 R 的 AC/DC 接近 0（恒包络）
  * 鉴频 Δθ 的方差显著大于 0
  * 鉴频波形为正弦（不是方波 → 不是 FSK）

### 3.2 连线（同 §2.2 但切到 FM）

| 操作 | 设置 |
| --- | --- |
| SIGLENT SDG2122X | `Mod` → `FM` → `Source Internal` |
| 载波 | 2 MHz, 1 Vpp |
| 频偏 | `Δf = 5 kHz`（即 `m_f·F`；先设 `Δf = 5 kHz, F = 1 kHz → m_f = 5` 验证上界） |
| 调制频率 | F = 1 kHz |
| Output | ON |

### 3.3 软件

#### 3.3.1 新增 Chisel 模块

* `chisel/src/main/scala/2023_D/FreqDiscriminator.scala`：鉴频模块，输出 `Δθ`（每 200 kHz 一次）。
* `chisel/src/main/scala/2023_D/FMClassifier.scala`：

  * 输出：`is_fm`（Bool）、`mf_estimate`（UFix(8,2)）、`dfmax_estimate`（24 bit 有符号 Hz）、`mod_freq`
* `chisel/src/main/scala/2023_D/ParameterEstimatorFM.scala`：

## 步骤 5 —— 检测 ASK（2ASK 码速率 `R_c`）

### 5.1 原理

* **2ASK**：`u_M(t) = Σ a_k · rect(t-kT_b) · cos(2π f_c t)`，`a_k ∈ {0,1}` NRZ，码速率 `R_c = 1/T_b ∈ {6, 8, 10} kbps`。
* **包络**：`R(t)` 呈两电平，0 / A_c 之间跳变（与 AM 区别：跳变沿是 NRZ 的"硬沿"，不是连续正弦）。
* **判决方法**：
  1. 直方图统计 R 的分布，看是否双峰；若是 → ASK 候选。
  2. 双峰间距 > 0.4·max(R) → 确认 ASK（AM 单峰）。
  3. 在 `R > 0.5·max(R)` 的区间里统计上升沿个数 N → `R_c_estimate = N / T_window`。选择最接近 6/8/10 kHz 的值。
* **数字解调输出**：`R > 0.5·max(R) ? 1 : 0`，送到 J11.J20
* **显示**：PL LED `011`；数码管显示码速率（6/8/10 → `0006/0008/0010`）。按键切换无用（CW/AM/FM 的 KEY 设计在检测为 ASK 时禁用，由顶层状态机屏蔽）。

### 5.2 连线（SIGLENT 切到 ASK）

* 部分 SDG2122X 不直接支持 ASK → 用 `Burst` 或 `AM Mod Source = External` 不行的话，**改用 MATLAB 把二进制序列写入 SDG2122X 的 Arb 模式**（250 MSa/s 任意波形：键控波形 `b_k·cos(2π f_c t)`），保存到仪器 U 盘后从仪器读出。
* 设置：ARB 长度 ≥ 1 ms，包含 6~10 个完整码元（≥ 6 个完整周期即可做统计）。

### 5.3 软件

* `chisel/src/main/scala/2023_D/EnvelopeThreshold.scala`：自适应门限（取包络直方图的谷点）。
* `chisel/src/main/scala/2023_D/EdgeCounter.scala`：上升沿计数，1 ms 滑窗。
* `chisel/src/main/scala/2023_D/ASKClassifier.scala`：综合双峰检测 + 边沿计数 + 最近邻 (6/8/10)。
* `chisel/src/main/scala/2023_D/DigitalDemodOut.scala`：把硬判决码流打到 J11.J20

### 5.4 上板实测

## 步骤 6 —— 检测 FSK（2FSK 码速率 `R_c` + 频移键控系数 `h`）

### 6.1 原理

* **2FSK**：`u_M(t) = Σ [a_k · cos(2π f_c1 t) + (1-a_k) · cos(2π f_c0 t)]`，NRZ；`R_c ∈ {6,8,10} kbps`；`h = |f_c1 - f_c0| / R_c ∈ [2, 5]`。
* **特征**：瞬时频率 `f_inst(n)` 呈两电平；包络 R 几乎恒定（恒包络）；R 的方差接近 CW、Δθ 的方差比 CW 大很多。
* **判决方法**：
  1. Δθ 直方图双峰 → FSK 候选；
  2. 两个峰位对应的频率 `f_c1`、`f_c0` → `Δf = |f_c1 - f_c0|`；
  3. Δθ 跳变沿计数 → `R_c`；
  4. `h_estimate = Δf / R_c`，约束到 `[2, 5]` 内。
* **显示**：PL LED `100`；数码管默认 `R_c`（如 `0006`），按 KEY1 切到 `h`（如 `2.0`），按 KEY2 切回 `R_c`。

| Hop Freq | `f_c1 = 2.012 MHz`（`Δf = 12 kHz, h=2, R_c=6 kbps`） |
| FSK Rate | `6 kHz` |

### 6.3 软件

## 步骤 7 —— 检测 PSK（2PSK 码速率 `R_c`）

## 步骤 8 —— 随机检测（全自动识别 + 参数显示 + 10 s 超时）

### 8.1 原理

* **顶层 FSM**：`IDLE → WAIT_TRIGGER (KEY 长按 1 s) → ACQUIRE (200 ms 采样 + 200 ms 分析) → DISPLAY (LED + 数码管) → TIMEOUT (10 s)`。
* **触发**：PL KEY1 按下后立即启动识别；其它 KEY 在识别过程中无效，避免误触；识别完成后再恢复按键切换显示项。
* **判决优先级**（按概率从小到大逐项排除，避免误判）：
  1. 鉴频方差 > 阈值_a **且** 包络方差 > 阈值_b → 不常见，先看是否 FSK/PSK；
  2. 包络双峰直方图（团间距 > 0.4·max）→ ASK；
  3. 鉴频双峰直方图（团间距 > 阈值）→ FSK；
  4. 相位跳变脉冲 > 阈值 → PSK；
  5. 包络方差 > 阈值_c **且** 鉴频方差 < 阈值_d → AM；
  6. 鉴频方差 > 阈值_e **且** 包络方差 < 阈值_f → FM；
  7. 全部方差都 < 阈值_g → CW。
* **超时**：进入 `ACQUIRE` 时拉起一个 200 MHz / 10^7 = 200 ms 周期×50 的计数器（10 s），到时强制进入 `TIMEOUT` 并把 PL LED 全灭、数码管显示 `----`（全段亮 → 看起来像 `8888`，作为失败指示）。

### 8.2 连线

### 8.3 软件

数码管位:   C17 C18 D17 D18         dig_sel[3:0], LVCMOS33, 高有效
J11 输出:   J20 (PIN20)              uo_ana, LVCMOS33, false_path  (避开 DAC/LED/PL)
```

> 注：B 通道、PL LED[3]、KEY[3]、J11.J20 都做了 `set_false_path`；其余按 40 ns（25 MHz）的多周期约束即可（WNS 一定富余）。
