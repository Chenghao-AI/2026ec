##  硬件基础

| 模块                                    | 关键事实                                                     |
| --------------------------------------- | ------------------------------------------------------------ |
| FPGA                                    | Xilinx Zynq-7000 **XC7Z020-2CLG400I**（PL 端 = 85K cells, **LUT 53,200**, **FF 106,400**, **DSP 220**, BRAM 4.9 Mb），400 脚 BGA。 |
| PL 时钟                                 | **50 MHz 单端有源晶振**，接到 **U18 (PL_GCLK)**，3.3V。      |
| PL 用户 LED（低有效）                   | LED1=**M14**, LED2=**M15**, LED3=**K16**, LED4=**J16**。     |
| PL 用户按键（低有效）                   | KEY1=+**N15**, KEY2=**N16**, KEY3=**T17**, KEY4=**R17**。    |
| 扩展口 J10（34 个 IO，BANK34 + BANK35） | PIN1=GND, PIN2=+5V, PIN3/4=差分对 (W19/W18), …, PIN10=+3.3V；保护 33Ω 串联；电平默认 3.3V（BANK35 可改 LDO 改电平）。 |
| 扩展口 J11（34 个 IO，全 BANK35）       | PIN1=GND, PIN2=+5V, PIN3=**F17** … PIN32=**H16**（DAC8571 SDA 实际就在 H16）；PIN33/34=GND, PIN39/40=+3.3V。 |
| ADC 模块                                | 双通道 **AD9226 12-bit 65 MSPS**；前端 AD8138 差分驱动；板上 SGM2036-3.3 LDO 把 VIN=5V 降到 3.3V；VIN=VCC=+5V，GND=0V；CLK=FPGA 给的 50 MHz（实测 8 pF 直插可行，125 pF 杜邦**会塌方**——ACLK 必须直插）。 |
| DAC模块                                 | AD9764 14-bit 125MSPS 并行双通道 DA 模块；板载限流电阻，信号端口控制电平为 3.3V，与 FPGA LVCMOS33 直接兼容；带差分转单端电路及 7 阶贝塞尔低通滤波器，SMA 接口输出（50Ω 阻抗，-3V~+3V，最大 6Vpp）；可跳帽选择内部 1.2V 基准或电位器调幅。 |
| 数码管                                  | **SR410401N 共阳**，4 位带小数点；FPGA 段输出**低有效**，位选**高有效**。 |
| 启动配置                                | J13 跳线 = SD/QSPI/JTAG；下板调试用**右两脚 → JTAG**。       |
| 板上 33Ω 串联排阻                       | J10 / J11 所有 IO 与 FPGA 之间都有 33Ω，保护外部过压/过流，并帮 ACLK 走线做阻尼。 |

> 这些信息是后续所有引脚约束 (XDC) 的唯一真值表。新做实验前，先把要用的引脚与上表对一遍。

### WSL 调起 Windows 程序的 4 个细节

1. **必须用 `cmd.exe /c "..."`**，不能直接 `/mnt/c/.../vivado.bat`——后者会因 Windows 端的 `$PATH` 缺失、绝对路径里有空格、UNC 路径限制而失败。已验证：

   ```bash
   cmd.exe /c "C:\\Xilinx\\Vivado\\2019.1\\bin\\vivado.bat -version"
   # → Vivado v2019.1 (64-bit)  SW Build 2552052 on Fri May 24 14:49:42 MDT 2019
   ```

2. **路径里有中文 / 空格** 没问题，但**不能**用 UNC（`\\wsl.localhost\...`）当工作目录——`cmd.exe` 不接受。建议：工作目录放在 `/mnt/c/Users/.../FPGA练习_windows端/Vivado/prj_xxx`，这是真实 Windows 路径。

3. **Vivado 批模式的日志位置**：`-log <path> -journal <path>`，统一写到 `Vivado/logs/<工程名>_<动作>.log`。

4. **MATLAB** 也要走 `cmd.exe /c "matlab.exe -batch ..."`；R2025b 强制 `-batch` 才不弹 GUI。

## 仪器支持

实验室中有四台仪器支持，涵盖了信号发生、信号观测、数值测量以及电路供电四大核心环节。以下为每台仪器的**主要功能**与**基本使用方法**。

---

### 第一台：泰克 Tektronix AFG31102 任意波形/函数发生器

#### **主要功能**

这是一款双通道的任意波形与函数发生器（AFG），其最大输出频率为 **100 MHz**，采样率为 **1 GS/s**。

* **产生标准波形**：可生成正弦波（Sine）、方波（Square）、脉冲波（Pulse）、三角波/锯齿波（Ramp）、噪声（Noise）和直流（DC）信号。
* **产生任意波形（Arb）**：用户可以通过编辑或导入特定的数学公式/数据，生成自定义的非标准波形。
* **信号调制与扫描**：支持幅频调制（AM、FM、PM、FSK、PWM等）、频率扫频（Sweep）以及突发模式（Burst，用于输出特定周期数量的波形）。
* **用途**：用于给待测电路提供输入激励信号。

####   基本使用方法

1. **开机**：按下左下角的电源按钮。
2. **选择波形**：在中间的 **BASIC MODE（基本模式）** 区域内，按下对应的波形按键（例如 `Sine` 正弦波、`Square` 方波、`Pulse` 脉冲波）。
3. **设置参数**：
   * 按下屏幕右侧偏下方的 `Frequency/Period`（频率/周期）按键，然后通过右侧的数字键盘、方向键或旋钮输入目标频率，最后按下对应的单位键（如 `kHz`、`MHz`）确认。
   * 同理，按下 `Amplitude/High`（幅度/高电平）设置信号幅度；按下 `Offset/Low`（偏置/低电平）设置直流偏置。
4. **连接输出**：将 BNC 电缆连接到下方的 `Ch1 Output` 或 `Ch2 Output` 接口。
5. **开启输出**：按下通道上方对应的黄色或蓝色 `On` 按键（灯亮起表示输出激活），此时物理端口开始输出电信号。

### 第二台：泰克 Tektronix MDO32 混合域示波器

#### **主要功能**

这是一款 **3 系列混合域示波器（MDO）**，带宽为 **500 MHz**，采样率为 **2.5 GS/s**。

* **时域分析（示波器）**：通过模拟通道（通道1、通道2）实时捕捉并显示电压随时间变化的波形。
* **频域分析（频谱仪）**：带有专用的 **RF** 射频输入端口，可用于观察信号的频谱（如频率分量、功率等）。
* **混合信号/数电分析**：支持数字通道（Digital Input），用于观测多路逻辑信号。
* **用途**：用于观测、测量和分析电路中各节点的电信号。

#### **基本使用方法**

1. **连接探头**：将示波器探头连接到下方的输入端口（例如通道 `1`）。将探头的接地夹接到电路板的地线（GND），探针接触需要测量的信号点。
2. **校准探头（选做）**：首次使用时，可将探头挂在右下角的 `Probe Comp`（探头补偿，2.5V 1kHz）金属片上，确保示波器显示的方波平整无过冲。
3. **自动设置（最快捷的起步方式）**：按下右下角的 `Autoset` 键，示波器会自动调整垂直档位、水平时基和触发电平，使波形稳定呈现在屏幕上。
4. **手动调节（核心操作）**：
   * **垂直控制（Vertical）**：使用 `Scale` 旋钮调节波形上下拉伸（每格代表的电压值，如 1V/div）；使用 `Position` 旋钮移动波形上下位置。
   * **水平控制（Horizontal）**：使用 `Scale` 旋钮调节波形左右展开或压缩（时间轴，如 100μs/div）；使用 `Position` 旋钮左右平移时间。
   * **触发控制（Trigger）**：通过调节 `Level`（触发电平）旋钮使波形稳定，不发生左右抖动。
5. **数据测量**：可通过触控屏或菜单选择 “Measure” 功能，自动测量频率、峰峰值（Vpp）、均方根（RMS）等参数。
6. **暂停/捕获**：按下右上角的 `Run/Stop`（运行/停止）可冻结波形，或按 `Single/Seq` 捕获单次瞬态信号。

### 第三台：福禄克 Fluke 45 双显示万用表

#### **主要功能**

这是一款高精度的台式五位半数字万用表。其最大的特色在于**双显示（Dual Display）**，能同时在屏幕上显示两种相关的测量数据（例如同时显示交流电压和该电压的频率）。

* **基本测量**：测量交直流电压（V）、交直流电流（A）、电阻（$\Omega$）、频率（FREQ）、二极管测试和通路蜂鸣测试（$\rightarrow| \bullet)))$）。
* **高级功能**：dB 功率测量、读数保持（HOLD）、最大/最小值记录（MN MX）、比较（COMP）等。

#### **基本使用方法**

1. **开机**：按下右下角的绿色 `POWER` 开关。
2. **插表笔**：
   * 黑色表笔始终插在左侧的 `COM`（公共端）插孔。
   * 红色表笔根据测量类型插入相应插孔：
     * 测电压、电阻、二极管、通断：插在 `V $\Omega$ $\rightarrow|$` 插孔。
     * 测微弱电流（100mA以内）：插在 `100 mA` 插孔（内有保险丝保护）。
     * 测大电流（最大10A）：插在 `10A` 插孔。
3. **选择测量功能**：
   * 测直流电压按 `V =--`，测交流电压按 `V ~`。
   * 测电阻按 `$\Omega$`。
   * 测通路（蜂鸣）或二极管按 `$\rightarrow| \bullet)))$` 键。
4. **读取数据**：将表笔接触待测点，屏幕将显示高精度读数。如果需要开启双显示（例如同时看交流电压和频率），可以先按 `V ~` 测量电压，再按下 `2ND` 键（第二显示），接着按 `FREQ` 键，副显示屏就会同步显示频率。

### 第四台：吉时利 Keithley 2231A-30-3 三通道直流电源

#### **主要功能**

这是一款可编程的多通道直流稳压电源，能够为电路板或器件提供稳定的直流电能。它拥有三个独立输出的通道：

* **CH1（通道1）**：输出范围 0 ~ 30V，最大电流 3A。
* **CH2（通道2）**：输出范围 0 ~ 30V，最大电流 3A。
* **CH3（通道3）**：输出范围 0 ~ 5V，最大电流 3A（常用于给 5V 或 3.3V 的数字芯片供电）。

#### **基本使用方法**

1. **开机**：按下左下角的绿色 `Power` 按钮。
2. **选择通道**：按下 `SELECT` 区域下的 `CH1`、`CH2` 或 `CH3` 键，屏幕将切换到对应通道的控制界面。
3. **设定电压（V-Set）和电流限制值（I-Set）**：
   * **设电压**：按下 `V-Set` 键，利用中间的数字键盘直接输入所需的电压值（例如输入 `5` ），然后按下 `Enter` 键确认。或者也可以通过右上角的大旋钮或方向键来进行微调。
   * **设限制电流**：为了防止电路短路烧毁，通常需要设置一个安全的电流限值。按下 `I-Set` 键，输入电流值（例如 `0.5` 表示 500mA 限流），然后按 `Enter` 键。
4. **接线**：使用香蕉头导线，将红线接入选定通道的正极（红孔 `+`），黑线接入负极（黑孔 `-`），并连接到待测电路的电源输入端。
5. **开启输出**：按下中央下方的 `On/Off` 键（灯亮起）。此时电源开始向外供电，屏幕会实时显示当前的输出电压和电路实际消耗的电流。

### 工程实践（失败版）

#### 2FSK 解调与参数估计原理分析

##### 信号数学模型
2FSK 信号输入 $u_M(t)$ 的数学表达为：
$$u_M(t) = A \cos(2\pi f_{c(i)} t + \phi_0)$$
其中发送码元为 `1` 时载频为 $f_{c1}$，发送码元为 `0` 时载频为 $f_{c0}$。
题目给定条件：
* 载频中心 $f_c = 2\text{ MHz}$
* 码速率 $R_c \in \{6\text{ kbps}, 8\text{ kbps}, 10\text{ kbps}\}$
* 移频键控系数 $h = \frac{|f_{c1} - f_{c0}|}{R_c} \in \{2, 3, 4, 5\}$
* 频差 $\Delta f_{pp} = |f_{c1} - f_{c0}| = h \cdot R_c$，取值范围为 $2 \times 6\text{ kHz} = 12\text{ kHz}$ 到 $5 \times 10\text{ kHz} = 50\text{ kHz}$。

#####  解调原理（数字下变频 + 正切微分解调法 / 正交相位鉴频）
针对 FPGA 内的高速数字信号处理，推荐采用**数字鉴频器（Digital Frequency Discriminator）**架构：
1. **正交下变频 (DDC)**：ADC 以 $f_s = 60\text{ MHz}$ 采样后，将信号分别乘以正弦波 $\sin(2\pi f_c n/f_s)$ 和余弦波 $\cos(2\pi f_c n/f_s)$（本地 $f_c = 2\text{ MHz}$ NCO），通过低通滤波器（LPF）后得到同相分量 $I(n)$ 和正交分量 $Q(n)$。
2. **相位微分鉴频**：根据瞬时相位公式 $\theta(n) = \arctan(Q/I)$，其瞬时频率偏移为：
   $$\Delta f(n) \propto \frac{d\theta}{dt} = \frac{I(n) \cdot \frac{dQ(n)}{dt} - Q(n) \cdot \frac{dI(n)}{dt}}{I^2(n) + Q^2(n)}$$
   在 FPGA 内部可简化为差分运算：
   $$D(n) = I(n) \cdot [Q(n) - Q(n-1)] - Q(n) \cdot [I(n) - I(n-1)]$$
3. **基端判决**：$D(n)$ 的符号即直接反映频率偏向 $f_{c1}$ 还是 $f_{c0}$。经过低通滤波与迟滞比较器判决后，输出还原的 0/1 二进制码流。

#####  参数估计原理（$R_c$ 与 $h$ 的测算）
1. **码速率 $R_c$ 估计**：
   * 抓取解调后二进制码流的边沿（上升沿/下降沿）。
   * 启动以 60 MHz 采样时钟计数的高精度计时计数器，统计相邻边沿之间的最小持续脉宽 $T_{\min}$。
   * 则码速率 $R_c = \frac{f_s}{N_{\min}}$（其中 $N_{\min}$ 为单码元对应的最小采样点数）。由于 $R_c$ 仅可能为 6k, 8k, 10k，通过阈值比较（例如：$N_{\min} \approx 10000$ 对应 6k，$7500$ 对应 8k，$6000$ 对应 10k）即可锁定 $R_c$。
2. **移频键控系数 $h$ 估计**：
   * 鉴频器输出的判决幅值绝对值平均值（或测量 $D(n)$ 正负峰值之间的差值）直接与频偏 $\Delta f_{pp} = |f_{c1} - f_{c0}|$ 成正比。
   * 计算得到频偏估值 $\Delta f_{pp}$ 后，根据公式 $h = \text{round}\left(\frac{\Delta f_{pp}}{R_c}\right)$ 计算得到 $h$（范围 2, 3, 4, 5）。

### 工程实践——verilog代码架构指正（修改版，但是修改后仍然失败）

####  现有架构失效的原因深度剖析（问题诊断）

在前一版本的实现中，系统在 Vivado 仿真及实测中屡屡退化为固定显示 $R_c = 8\text{k}$、$h = 2$ [3]，其根本原因并非 FPGA 硬件性能不足，而是 DSP 算法流水线存在以下三大致命设计缺陷 [1, 3]：

##### 缺陷 1：高采样率下的“微小频偏失真”
* **物理算式**：当载波 $f_c = 2\text{ MHz}$，$R_c = 6\text{ kbps}$，$h = 2$ 时 [2]：
  $$\Delta f_{pp} = h \cdot R_c = 12\text{ kHz}$$
  $f_{c0} = 1.994\text{ MHz}$ 与 $f_{c1} = 2.006\text{ MHz}$ 的频率相对差值仅为 **0.3%**。
* **时域失真**：AD9226 运行在 60 MSPS 采样率下 [1]，一个 $2\text{ MHz}$ 周期对应 30 个采样点。$12\text{ kHz}$ 的频偏在单周期内仅造成 **0.18 个采样点的相移**。
* **结论**：若不经过降采样直接在 60 MSPS 高速时钟下进行鉴频/过零计数，ADC 的高频噪声和采样抖动会彻底淹没这 0.18 个采样点，导致鉴频器输出严重的噪声毛刺 [1, 3]。

##### 缺陷 2：缺少数字下变频（DDC）与抽取降采样
旧架构直接在 60 MSPS 下对原始 ADC 数据进行过零或鉴频运算 [3]。
* 60 MSPS 相比于 $10\text{ kbps}$ 的基带码率，过采样率高到 **6000 倍**，带外噪声极其严重 [2]。
* 缺乏低通抽取滤波（Decimation），导致频域分辨率严重不足，鉴频器输出的峰峰值幅度失真，最终使得 $h$ 的辨识逻辑失效 [3]。

##### 缺陷 3：码率提取与阈值判决逻辑缺少迟滞与滑动滤波
* 旧逻辑直接对噪声毛刺未滤净的解调波形进行边沿计数，导致计数值 $T_{\min}$ 极其不稳定（频繁出现单脉冲伪毛刺导致 $T_{\min}$ 被误刷新为极小值）[3]。
* 当计数值越界后，状态机触发了默认退化保护（Fallback），强制锁定输出 $R_c = 8\text{k}$、$h = 2$ [3]。

#### 重构后的 DSP 数字处理流水线架构

为彻底解决上述问题，将 FPGA 内部的数字信号处理流水线重构为**“正交数字下变频 (DDC) $\rightarrow$ 抽取滤波 $\rightarrow$ 相位微分解调 $\rightarrow$ 迟滞平滑 $\rightarrow$ 特征提取”**的标准架构。

```
                       ┌─────────────────────────────────────────────────────────┐
                       │                   重构后的 DSP 处理流水线                │
                       └─────────────────────────────────────────────────────────┘
                                                                
 ADC 60MSPS ──> [ 2MHz NCO 混频 ] ──> [ FIR 低通/60倍抽取 ] ──> [ 1MSPS 离散相位微分解调 ]
                                                                             │
                                                                             ▼
 DAC CHA <── [ 14-bit 缩放 ] <── [ 迟滞比较/平滑滤波 ] <── [ 瞬时频偏信号 D(k) ]
  基带波形                                     │                             │
                                              ▼                             ▼
                                    [ 最小码元周期测量 ]           [ 频偏幅度峰值统计 ]
                                              │                             │
                                              ▼                             ▼
                                    [ Rc 辨识 (6k/8k/10k) ]       [ h 辨识 (2/3/4/5) ]
                                              │                             │
                                              └──────────────┬──────────────┘
                                                             ▼
                                                    [ PL LED 编码输出 ]
```

##### 关键技术指标与参数规划：
1. **DDC 混频**：NCO 产生 $2.0\text{ MHz}$ 的正交正余弦信号 $I_{nco} = \cos(2\pi \cdot 2\text{M} \cdot t)$，$Q_{nco} = -\sin(2\pi \cdot 2\text{M} \cdot t)$。
2. **抽取滤波器（FIR Decimator）**：抽取倍数为 60，将数据速率从 **60 MSPS** 降至 **1 MSPS**（采样间隔 $T_s = 1\mu s$）。此时 $12\text{ kHz}$ 频偏在 1 MSPS 采样率下得到了 60 倍的相对放大，噪声被大幅抑制。
3. **1 MSPS 相位微分解调器**：
   $$D(k) = I(k) \cdot [Q(k) - Q(k-1)] - Q(k) \cdot [I(k) - I(k-1)]$$
4. **$R_c$ 码率判定标准（1 MSPS 计数周期下）**：
   * $6\text{ kbps} \Rightarrow 166.7\mu s$（对应 167 个 1MSPS 点） $\rightarrow$ 判定范围：$T > 145$
   * $8\text{ kbps} \Rightarrow 125.0\mu s$（对应 125 个 1MSPS 点） $\rightarrow$ 判定范围：$112 < T \le 145$
   * $10\text{ kbps} \Rightarrow 100.0\mu s$（对应 100 个 1MSPS 点）$\rightarrow$ 判定范围：$T \le 112$
5. **$h$ 键控系数判定标准**：
   * 测定 $D(k)$ 平坦区的峰峰值差值 $\Delta D = D_{high} - D_{low}$，该值严格正比于实际频偏 $\Delta f_{pp} = h \cdot R_c$。
   * $h = \text{round}\left( \frac{\Delta f_{est}}{R_c} \right)$。

####  核心 Verilog 处理逻辑关键代码段（代码示例，实践写代码中可修改）

##### 正交微分解调器与平滑滤波 (Differential Demodulator)
*在 1 MSPS 抽取时钟域（`clk_1m`）下运行：*

```verilog
module fsk_demod_core (
    input  wire        clk_1m,       // 1 MHz 抽取后的处理时钟
    input  wire        rst_n,
    input  wire signed [15:0] i_data, // DDC 抽取后的 I 通道 (1MSPS)
    input  wire signed [15:0] q_data, // DDC 抽取后的 Q 通道 (1MSPS)
    output reg  signed [31:0] d_out,  // 瞬时频偏鉴频输出
    output reg         baseband_bit   // 解调恢复的二进制基带 (0/1)
);

    // 1. 延迟打拍
    reg signed [15:0] i_d1, q_d1;
    always @(posedge clk_1m or negedge rst_n) begin
        if (!rst_n) begin
            i_d1 <= 16'd0;
            q_d1 <= 16'd0;
        end else begin
            i_d1 <= i_data;
            q_d1 <= q_data;
        end
    end

    // 2. 离散差分交叉乘加: D(k) = I(k)*(Q(k)-Q(k-1)) - Q(k)*(I(k)-I(k-1))
    wire signed [15:0] delta_i = i_data - i_d1;
    wire signed [15:0] delta_q = q_data - q_d1;
    
    wire signed [31:0] mult1   = i_data * delta_q;
    wire signed [31:0] mult2   = q_data * delta_i;
    wire signed [31:0] d_raw   = mult1 - mult2;

    // 3. 移动平均滤波 (Moving Average Filter, 8点滑动窗口)
    reg signed [31:0] shift_reg[0:7];
    integer k;
    reg signed [34:0] sum;
    
    always @(posedge clk_1m or negedge rst_n) begin
        if (!rst_n) begin
            for (k=0; k<8; k=k+1) shift_reg[k] <= 32'd0;
            d_out <= 32'd0;
        end else begin
            shift_reg[0] <= d_raw;
            for (k=1; k<8; k=k+1) shift_reg[k] <= shift_reg[k-1];
            
            // 累加求均值
            d_out <= (shift_reg[0] + shift_reg[1] + shift_reg[2] + shift_reg[3] +
                      shift_reg[4] + shift_reg[5] + shift_reg[6] + shift_reg[7]) >>> 3;
        end
    end

    // 4. 施密特迟滞比较器 (Hysteresis Comparator)，防止零点抖动
    parameter signed [31:0] TH_HIGH = 32'd5000;   // 迟滞高门限 (根据实际增益调整)
    parameter signed [31:0] TH_LOW  = -32'd5000;  // 迟滞低门限

    always @(posedge clk_1m or negedge rst_n) begin
        if (!rst_n) begin
            baseband_bit <= 1'b0;
        end else begin
            if (d_out > TH_HIGH)
                baseband_bit <= 1'b1;
            else if (d_out < TH_LOW)
                baseband_bit <= 1'b0;
            // 在门限之间保持上一状态
        end
    end

endmodule
```

##### 消除毛刺的码率 $R_c$ 辨识逻辑
*统计连续平坦码元精确定时时间 $T$，消除单点冲激噪点：*

```verilog
module rc_estimator (
    input  wire       clk_1m,         // 1 MHz 时钟 (计数精度 1us)
    input  wire       rst_n,
    input  wire       baseband_bit,   // 迟滞比较后的干净基带信号
    output reg  [1:0] rc_code         // 2'b00: 6k, 2'b01: 8k, 2 meb: 10k
);

    reg baseband_d1;
    always @(posedge clk_1m) baseband_d1 <= baseband_bit;
    wire edge_detect = (baseband_bit ^ baseband_d1); // 任意边沿检测

    reg [15:0] pulse_cnt;
    reg [15:0] t_min;
    reg [19:0] window_timer;

    always @(posedge clk_1m or negedge rst_n) begin
        if (!rst_n) begin
            pulse_cnt    <= 16'd0;
            t_min        <= 16'hFFFF;
            window_timer <= 20'd0;
            rc_code      <= 2'b01; // 默认 8k
        end else begin
            window_timer <= window_timer + 1'b1;
            
            if (edge_detect) begin
                // 忽略小于 50us 的伪毛刺 (大于 20kHz 频段的干扰)
                if (pulse_cnt > 16'd50 && pulse_cnt < t_min) begin
                    t_min <= pulse_cnt;
                end
                pulse_cnt <= 16'd0;
            end else begin
                pulse_cnt <= pulse_cnt + 1'b1;
            end

            // 每 100ms (100,000 个 1MSPS 点) 完成一次统计与判决更新
            if (window_timer >= 20'd100000) begin
                window_timer <= 20'd0;
                
                // 阈值分类判决
                if (t_min > 16'd145)         // ~167us (6kbps)
                    rc_code <= 2'b00; // 6k
                else if (t_min > 16 meb112)  // ~125us (8kbps)
                    rc_code <= 2'b01; // 8k
                else                         // ~100us (10kbps)
                    rc_code <= 2'b10; // 10k

                t_min <= 16'hFFFF; // 充值最小脉宽统计
            end
        end
    end

endmodule
```

#####  频偏 $\Delta f$ 与键控系数 $h$ 辨识逻辑
*利用正负半周平坦区的平均幅度估算实际频偏，再除以 $R_c$ 求解 $h$：*

```verilog
module h_estimator (
    input  wire        clk_1m,
    input  wire        rst_n,
    input  wire signed [31:0] d_out,   // 鉴频器平滑输出
    input  wire [1:0]  rc_code,        // 已辨识出的 Rc (00:6k, 01:8k, 10:10k)
    output reg  [1:0]  h_code          // 00: h=2, 01: h=3, 10: h=4, 11: h=5
);

    // 峰值与谷值采样统计
    reg signed [31:0] d_max, d_min;
    reg [19:0] stat_timer;

    always @(posedge clk_1m or negedge rst_n) begin
        if (!rst_n) begin
            d_max      <= -32'sd2147483648;
            d_min      <=  32'sd2147483647;
            stat_timer <= 20'd0;
            h_code     <= 2'b00; // 默认 h=2
        end else begin
            stat_timer <= stat_timer + 1'b1;

            if (d_out > d_max) d_max <= d_out;
            if (d_out < d_min) d_min <= d_out;

            // 每 100ms 进行一次系数估计
            if (stat_timer >= 20'd100000) begin
                stat_timer <= 20'd0;
                
                // 计算峰峰幅度差值 Delta_D，正比于 (h * Rc)
                begin : EVAL_H
                    reg [31:0] delta_d;
                    reg [31:0] est_freq_khz;
                    reg [31:0] curr_rc_khz;
                    reg [31:0] calculated_h;

                    delta_d = d_max - d_min;
                    
                    // 幅度到频偏(kHz)的标定映射 (K_CALIB 需根据 FIR 增益标定，此处为示定比例)
                    est_freq_khz = delta_d >> 12; 

                    curr_rc_khz = (rc_code == 2'b00) ? 32'd6 :
                                  (rc_code == 2'b01) ? 32'd8 : 32'd10;

                    // 计算 h = Delta_f / Rc
                    calculated_h = (est_freq_khz + (curr_rc_khz >> 1)) / curr_rc_khz;

                    // 映射到 2, 3, 4, 5
                    if (calculated_h <= 2)      h_code <= 2'b00; // h=2
                    else if (calculated_h == 3) h_code <= 2'b01; // h=3
                    else if (calculated_h == 4) h_code <= 2'b10; // h=4
                    else                        h_code <= 2 meb11; // h=5
                end

                // 重置统计最大最小值
                d_max <= -32'sd2147483648;
                d_min <=  32'sd2147483647;
            end
        end
    end

endmodule
```

####  硬件验证与调试检查点（Checkpoints）

重新生成 Bitstream 下板调试时，请依序检查以下物理节点 [2, 3]：

1. **DAC 输出 $u_o$ 的示波器测量**：
   * 将示波器通道 2 接至 AD9764 CHA 输出端 [1]。
   * 观察 $u_o$ 是否为极其整洁的 1Vpp 二进制基带方波 [2]。若方波边缘有高频毛刺，需增加 `TH_HIGH`/`TH_LOW` 迟滞比较器的门限。
2. **$R_c$ 估计验证**：
   * 在信号发生器上分别切换 6kHz、8kHz、10kHz 码率 [2]。
   * 按下 KEY1，观察 LED4~LED1 是否能无延迟、无误判地在 `0110`(6k)、`1000`(8k)、`1010`(10k) 之间稳定切换 [2]。
3. **$h$ 键控系数估算标定**：
   * 在信号发生器固定 $R_c = 8\text{ kHz}$ 下，依次更改 Hop Frequency 为 $2.016\text{ MHz}$ ($h=2$)、$2.024\text{ MHz}$ ($h=3$)、$2.032\text{ MHz}$ ($h=4$)、$2.040\text{ MHz}$ ($h=5$) [2]。
   * 按下 KEY2，观察 LED 显示是否精准对应 `0010`、`0011`、`0100`、`0101` [2]。若有偏差，微调 `est_freq_khz = delta_d >> K` 中的缩放位移因子即可完成校准。
