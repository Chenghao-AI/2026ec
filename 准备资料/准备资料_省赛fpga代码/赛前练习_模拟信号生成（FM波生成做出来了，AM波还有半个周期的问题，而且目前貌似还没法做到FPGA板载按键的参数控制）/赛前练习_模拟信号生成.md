##  硬件基础

| 模块                                    | 关键事实                                                     |
| --------------------------------------- | ------------------------------------------------------------ |
| FPGA                                    | Xilinx Zynq-7000 **XC7Z020-2CLG400I**（PL 端 = 85K cells, **LUT 53,200**, **FF 106,400**, **DSP 220**, BRAM 4.9 Mb），400 脚 BGA。 |
| PL 时钟                                 | **50 MHz 单端有源晶振**，接到 **U18 (PL_GCLK)**，3.3V。      |
| PL 用户 LED（低有效）                   | LED1=**M14**, LED2=**M15**, LED3=**K16**, LED4=**J16**。     |
| PL 用户按键（低有效）                   | KEY1=+**N15**, KEY2=**N16**, KEY3=**T17**, KEY4=**R17**。    |
| 扩展口 J10（34 个 IO，BANK34 + BANK35） | PIN1=GND, PIN2=+5V, PIN3/4=差分对 (W19/W18), …, PIN10=+3.3V；保护 33Ω 串联；电平默认 3.3V（BANK35 可改 LDO 改电平）。 |
| 扩展口 J11（34 个 IO，全 BANK35）       | PIN1=GND, PIN2=+5V, PIN3=**F17** … PIN32=**H16**（DAC8571 SDA 实际就在 H16）；PIN33/34=GND, PIN39/40=+3.3V。 |
| ADC 模块                                | 双通道 **AD9226 12-bit 65 MSPS**；前端 AD8138 差分驱动；板上 SGM2036-3.3 LDO 把 VIN=5V 降到 3.3V；VIN=VCC=+5V，GND=0V；CLK=FPGA 给的 50 MHz（实测 8 pF 直插可行，125 pF 杜邦**会塌方**——ACLK 必须直插）。 |
| DAC 模块                                | AD9764 14-bit 125MSPS 并行双通道 DA 模块；板载限流电阻，信号端口控制电平为 3.3V，与 FPGA LVCMOS33 直接兼容；带差分转单端电路及 7 阶贝塞尔低通滤波器，SMA 接口输出（50Ω 阻抗，-3V~+3V，最大 6Vpp）；可跳帽选择内部 1.2V 基准或电位器调幅。 |
| 数码管                                  | **SR410401N 共阳**，4 位带小数点；FPGA 段输出**低有效**，位选**高有效**。 |
| 启动配置                                | J13 跳线 = SD/QSPI/JTAG；下板调试用**右两脚 → JTAG**。       |
| 板上 33Ω 串联排阻                       | J10 / J11 所有 IO 与 FPGA 之间都有 33Ω，保护外部过压/过流，并帮 ACLK 走线做阻尼。 |

### WSL 调起 Windows 程序的 4 个细节

1. **必须用 `cmd.exe /c "..."`**，不能直接 `/mnt/c/.../vivado.bat`——后者会因 Windows 端的 `$PATH` 缺失、绝对路径里有空格、UNC 路径限制而失败。已验证：

   ```bash
   cmd.exe /c "C:\\Xilinx\\Vivado\\2019.1\\bin\\vivado.bat -version"
   # → Vivado v2019.1 (64-bit)  SW Build 2552052 on Fri May 24 14:49:42 MDT 2019
   ```

2. **路径里有中文 / 空格** 没问题，但**不能**用 UNC（`\\wsl.localhost\...`）当工作目录——`cmd.exe` 不接受。建议：工作目录放在 `/mnt/c/Users/.../FPGA练习_windows端/Vivado/prj_xxx`，这是真实 Windows 路径。

3. **Vivado 批模式的日志位置**：`-log <path> -journal <path>`，统一写到 `Vivado/logs/<工程名>_<动作>.log`。

4. **MATLAB** 也要走 `cmd.exe /c "matlab.exe -batch ..."`；R2025b 强制 `-batch` 才不弹 GUI。

## 仪器支持

实验室中有四台仪器支持，涵盖了信号发生、信号观测、数值测量以及电路供电四大核心环节。以下为每台仪器的**主要功能**与**基本使用方法**。

---

### 第一台：泰克 Tektronix AFG31102 任意波形/函数发生器

#### **主要功能**

这是一款双通道的任意波形与函数发生器（AFG），其最大输出频率为 **100 MHz**，采样率为 **1 GS/s**。

* **产生标准波形**：可生成正弦波（Sine）、方波（Square）、脉冲波（Pulse）、三角波/锯齿波（Ramp）、噪声（Noise）和直流（DC）信号。
* **产生任意波形（Arb）**：用户可以通过编辑或导入特定的数学公式/数据，生成自定义的非标准波形。
* **信号调制与扫描**：支持幅频调制（AM、FM、PM、FSK、PWM等）、频率扫频（Sweep）以及突发模式（Burst，用于输出特定周期数量的波形）。
* **用途**：用于给待测电路提供输入激励信号。

####   基本使用方法

1. **开机**：按下左下角的电源按钮。
2. **选择波形**：在中间的 **BASIC MODE（基本模式）** 区域内，按下对应的波形按键（例如 `Sine` 正弦波、`Square` 方波、`Pulse` 脉冲波）。
3. **设置参数**：
   * 按下屏幕右侧偏下方的 `Frequency/Period`（频率/周期）按键，然后通过右侧的数字键盘、方向键或旋钮输入目标频率，最后按下对应的单位键（如 `kHz`、`MHz`）确认。
   * 同理，按下 `Amplitude/High`（幅度/高电平）设置信号幅度；按下 `Offset/Low`（偏置/低电平）设置直流偏置。
4. **连接输出**：将 BNC 电缆连接到下方的 `Ch1 Output` 或 `Ch2 Output` 接口。
5. **开启输出**：按下通道上方对应的黄色或蓝色 `On` 按键（灯亮起表示输出激活），此时物理端口开始输出电信号。

---

### 第二台：泰克 Tektronix MDO32 混合域示波器

#### **主要功能**

这是一款 **3 系列混合域示波器（MDO）**，带宽为 **500 MHz**，采样率为 **2.5 GS/s**。

* **时域分析（示波器）**：通过模拟通道（通道1、通道2）实时捕捉并显示电压随时间变化的波形。
* **频域分析（频谱仪）**：带有专用的 **RF** 射频输入端口，可用于观察信号的频谱（如频率分量、功率等）。
* **混合信号/数电分析**：支持数字通道（Digital Input），用于观测多路逻辑信号。
* **用途**：用于观测、测量和分析电路中各节点的电信号。

#### **基本使用方法**

1. **连接探头**：将示波器探头连接到下方的输入端口（例如通道 `1`）。将探头的接地夹接到电路板的地线（GND），探针接触需要测量的信号点。
2. **校准探头（选做）**：首次使用时，可将探头挂在右下角的 `Probe Comp`（探头补偿，2.5V 1kHz）金属片上，确保示波器显示的方波平整无过冲。
3. **自动设置（最快捷的起步方式）**：按下右下角的 `Autoset` 键，示波器会自动调整垂直档位、水平时基和触发电平，使波形稳定呈现在屏幕上。
4. **手动调节（核心操作）**：
   * **垂直控制（Vertical）**：使用 `Scale` 旋钮调节波形上下拉伸（每格代表的电压值，如 1V/div）；使用 `Position` 旋钮移动波形上下位置。
   * **水平控制（Horizontal）**：使用 `Scale` 旋钮调节波形左右展开或压缩（时间轴，如 100μs/div）；使用 `Position` 旋钮左右平移时间。
   * **触发控制（Trigger）**：通过调节 `Level`（触发电平）旋钮使波形稳定，不发生左右抖动。
5. **数据测量**：可通过触控屏或菜单选择 “Measure” 功能，自动测量频率、峰峰值（Vpp）、均方根（RMS）等参数。
6. **暂停/捕获**：按下右上角的 `Run/Stop`（运行/停止）可冻结波形，或按 `Single/Seq` 捕获单次瞬态信号。

### 第三台：福禄克 Fluke 45 双显示万用表

#### **主要功能**

这是一款高精度的台式五位半数字万用表。其最大的特色在于**双显示（Dual Display）**，能同时在屏幕上显示两种相关的测量数据（例如同时显示交流电压和该电压的频率）。

* **基本测量**：测量交直流电压（V）、交直流电流（A）、电阻（$\Omega$）、频率（FREQ）、二极管测试和通路蜂鸣测试（$\rightarrow| \bullet)))$）。
* **高级功能**：dB 功率测量、读数保持（HOLD）、最大/最小值记录（MN MX）、比较（COMP）等。

#### **基本使用方法**

1. **开机**：按下右下角的绿色 `POWER` 开关。
2. **插表笔**：
   * 黑色表笔始终插在左侧的 `COM`（公共端）插孔。
   * 红色表笔根据测量类型插入相应插孔：
     * 测电压、电阻、二极管、通断：插在 `V $\Omega$ $\rightarrow|$` 插孔。
     * 测微弱电流（100mA以内）：插在 `100 mA` 插孔（内有保险丝保护）。
     * 测大电流（最大10A）：插在 `10A` 插孔。
3. **选择测量功能**：
   * 测直流电压按 `V =--`，测交流电压按 `V ~`。
   * 测电阻按 `$\Omega$`。
   * 测通路（蜂鸣）或二极管按 `$\rightarrow| \bullet)))$` 键。
4. **读取数据**：将表笔接触待测点，屏幕将显示高精度读数。如果需要开启双显示（例如同时看交流电压和频率），可以先按 `V ~` 测量电压，再按下 `2ND` 键（第二显示），接着按 `FREQ` 键，副显示屏就会同步显示频率。

---

### 第四台：吉时利 Keithley 2231A-30-3 三通道直流电源

#### **主要功能**

这是一款可编程的多通道直流稳压电源，能够为电路板或器件提供稳定的直流电能。它拥有三个独立输出的通道：

* **CH1（通道1）**：输出范围 0 ~ 30V，最大电流 3A。
* **CH2（通道2）**：输出范围 0 ~ 30V，最大电流 3A。
* **CH3（通道3）**：输出范围 0 ~ 5V，最大电流 3A（常用于给 5V 或 3.3V 的数字芯片供电）。

#### **基本使用方法**

1. **开机**：按下左下角的绿色 `Power` 按钮。
2. **选择通道**：按下 `SELECT` 区域下的 `CH1`、`CH2` 或 `CH3` 键，屏幕将切换到对应通道的控制界面。
3. **设定电压（V-Set）和电流限制值（I-Set）**：
   * **设电压**：按下 `V-Set` 键，利用中间的数字键盘直接输入所需的电压值（例如输入 `5` ），然后按下 `Enter` 键确认。或者也可以通过右上角的大旋钮或方向键来进行微调。
   * **设限制电流**：为了防止电路短路烧毁，通常需要设置一个安全的电流限值。按下 `I-Set` 键，输入电流值（例如 `0.5` 表示 500mA 限流），然后按 `Enter` 键。
4. **接线**：使用香蕉头导线，将红线接入选定通道的正极（红孔 `+`），黑线接入负极（黑孔 `-`），并连接到待测电路的电源输入端。
5. **开启输出**：按下中央下方的 `On/Off` 键（灯亮起）。此时电源开始向外供电，屏幕会实时显示当前的输出电压和电路实际消耗的电流。

##### 系统主时钟规划 (125 MSPS)
* **采样率选择**：调用 FPGA 内部 MMCM IP 核，将 PL 端 $50\text{ MHz}$ 输入晶振倍频至 **$125\text{ MHz}$** 作为 DSP 核心计算与 DAC 数据更新的同源时钟（$f_{dac} = 125\text{ MSPS}$）。
* **奈奎斯特裕量**：针对 $15\text{ MHz}$ 载波，$125\text{ MSPS}$ 采样率可在单周期内提供约 $8.33$ 个采样点，高频阶梯镜像落在 $125 \pm 15 = 110\text{ MHz}$，远高于板载 $32\text{ MHz}$ 贝塞尔低通滤波器的截止频率，可确保输出光滑无阶梯的纯净模拟波形。

#####  按键消抖与参数状态机 (State Machine)
内部硬件逻辑实现 $20\text{ ms}$ 按键去抖动与下降沿检测检测模块，控制三大调制参数状态：
* **KEY1 状态机（全局峰峰值 $V_{pp}$ 控制，控制 CHA/CHB 同步缩放）**：
  * **状态循环**：$100\text{ mV} \rightarrow 200\text{ mV} \rightarrow 300\text{ mV} \rightarrow \dots \rightarrow 1000\text{ mV} (1\text{ V}) \rightarrow 100\text{ mV}$（共 10 级，步进 $100\text{ mV}$，复位默认 $100\text{ mV}$）。
  * **增益映射**：根据选择的 $V_{pp}$，计算对应的 14-bit 满量程数字幅度缩放因子 $K_{amp}(V_{pp})$。
* **KEY2 状态机（CHA AM 调制度 $m_{am}$ 控制）**：
  * **状态循环**：$0.3 \rightarrow 0.4 \rightarrow 0.5 \rightarrow 0.6 \rightarrow 0.7 \rightarrow 0.8 \rightarrow 0.9 \rightarrow 0.3$（共 7 级，步进 $0.1$，复位默认 $0.3$）。
* **KEY3 状态机（CHB FM 最大频偏 $\Delta f$ 控制）**：
  * **状态循环**：$3.0\text{ kHz} \rightarrow 3.2\text{ kHz} \rightarrow 3.4\text{ kHz} \rightarrow \dots \rightarrow 5.0\text{ kHz} \rightarrow 3.0\text{ kHz}$（共 11 级，步进 $0.2\text{ kHz}$，复位默认 $3.0\text{ kHz}$）。

#####  调制波与载波 DDS 控制字计算
设相位累加器位宽 $N = 32$ bit，$f_{dac} = 125\text{ MHz}$：
* **基带调制波 DDS ($f_m = 10\text{ kHz}$)**：
  $$\Delta \theta_m = \frac{10\text{ kHz} \times 2^{32}}{125\text{ MHz}} = 343,597$$
  通过正弦查找表（ROM）输出标准化归一化基带调制信号 $m(t) \in [-1.0, +1.0]$（16-bit 有符号定点数 Q1.15 表示）。
* **载波中心频率 DDS ($f_c = 15\text{ MHz}$)**：
  $$\Delta \theta_c = \frac{15\text{ MHz} \times 2^{32}}{125\text{ MHz}} = 515,396,075$$

##### CHA：调幅（AM）数据流流水线
1. **包络合成**：将基带调制波 $m(t)$ 乘以调制度 $m_{am}$，并叠加直流偏置 $1.0$：
   $$\text{Env}(t) = 1.0 + m_{am} \cdot m(t)$$
   由于 $m_{am} \in [0.3, 0.9]$，包络动态范围为 $[0.1, 1.9]$。
2. **载波调制**：包络与 $15\text{ MHz}$ 载波 $c(t) = \cos(2\pi f_c t)$ 进行有符号乘法：
   $$s_{AM\_raw}(t) = \text{Env}(t) \times c(t)$$
3. **幅度缩放与归一化**：
   * 在 `1-2 REF-EN`（1.2V 内部基准）模式下，开路满量程电压为 $\pm 3.0\text{ V}$（$6.0\text{ V}_{pp}$），对应数字域 $16384\text{ LSB}$（即 $1\text{ V}_{pp} \approx 2730\text{ LSB}$，零偏为 $8192\text{ LSB}$）。
   * 考虑到 AM 信号包络最大膨胀系数为 $1 + m_{am}$，为了在最高调制度 $m_{am}=0.9$ 且 $V_{pp}=1\text{ V}$ 时不发生数字溢出（Clipping），对原始幅度进行增益校准与无符号截断：
   $$\text{CHA\_DATA}[13:0] = 8192 + \text{Round}\left( s_{AM\_raw}(t) \times \frac{K_{amp}(V_{pp})}{1 + m_{am}} \right)$$

#####  CHB：调频（FM）数据流流水线
1. **瞬时频偏与相位累加**：
   * 目标频偏 $\Delta f \in [3.0\text{ kHz}, 5.0\text{ kHz}]$ 对应的相位控制字偏移量为：
     $$\Delta \theta_{dev} = \frac{\Delta f \times 2^{32}}{125\text{ MHz}}$$
     （当 $\Delta f = 3.0\text{ kHz}$ 时，$\Delta \theta_{dev} = 103,079$；当 $\Delta f = 5.0\text{ kHz}$ 时，$\Delta \theta_{dev} = 171,798$）。
   * 每个 $125\text{ MHz}$ 时钟周期，载波相位累加器的步进控制字动态调整为：
     $$\Delta \theta_{FM}(t) = \Delta \theta_c + \text{Round}\left( \Delta \theta_{dev} \times m(t) \right)$$
2. **波形查表与幅度映射**：
   * 将相位累加器高位作为地址查正弦 ROM，得到纯净的瞬时调频波 $c_{FM}(t) = \cos\left( \sum \Delta \theta_{FM}(t) \right)$。
   * 结合 $V_{pp}$ 缩放系数及 $8192$ 直流中点叠加，输出无符号 14-bit 正码：
     $$\text{CHB\_DATA}[13:0] = 8192 + \text{Round}\left( c_{FM}(t) \times K_{amp}(V_{pp}) \right)$$

###  原因分析与排查建议

####  AM 包络半周期矩形方块（$50\ \mu\text{s}$ 饱和）排查
* **分析**：$10\text{ kHz}$ 基带信号 $m(t)$ 的总周期为 $100\ \mu\text{s}$，正半轴（$m(t) \ge 0$）持续 $50\ \mu\text{s}$，负半轴（$m(t) < 0$）持续 $50\ \mu\text{s}$。前 $50\ \mu\text{s}$ 计算正确，后 $50\ \mu\text{s}$ 饱和拉满，**100% 锁定为有符号数（Signed）负半轴乘法溢出**。
* **建议**：
  1. 检查 Verilog / Chisel 代码中基带正弦波 $m(t)$ 及调制度 $m_{am}$ 的变量类型，确保显式声明为有符号数（`signed` / `SInt`）。
  2. 当 $m(t) < 0$ 时，补码最高位 MSB 为 1（如 `-1` 补码为 `16'hFFFF`）。若变量未加 `$signed`，乘法器会将补码误当成无符号数 $65535$ 参与运算，导致包络计算值剧烈膨胀顶格。请确保包络乘法与载波调制乘法均使用双 `signed` 格式，并在最终输出前加上 `0 ~ 16383` 的**饱和截断（Saturation Guard）**保护。

####  FM “上密下稀”、负偏置与 $V_{pp}$ 跳动排查
* **分析 1（负偏置与下发散）**：
  * AD9764 接收 14-bit 无符号正码（$0 \sim 16383$），其中 $8192$ 映射为 $0\text{V}$。如果 FPGA 在输出前没有正确叠加 `+ 8192` 中点偏置，数据将全落在负电压区。
  * 检查 Vivado 的 XDC 约束文件，核对 CHB 最高位 `B13`（J11 的 Pin 24 / FPGA 管脚 `M17`）是否约束成功或虚焊。若最高位恒为 0，数据上限被限制在 $8191$，导致输出全为负电压。
* **分析 2（125 MSPS 并行总线毛刺）**：
  * 在 $125\text{ MHz}$ 高速更新下（周期仅 $8\text{ ns}$），数据线的建立/保持时间极其紧迫。数据位锁存误码会引发向下跳变的尖峰毛刺（Glitch）。请确保 FPGA 输出给 AD9764 的转换时钟（`CA`/`CB`，脚号 `G19`/`L17`）配置了 **180° 相位反相（反相驱动）**。

#### PL KEY1 ~ KEY3 按键响应失效排查
* **分析**：板载按键为低有效（按压接 GND）。按键按下无反应通常是因为消抖脉冲未触发状态机，或状态机的输出寄存器未成功接入 DSP 缩放因子。
* **建议**：
  1. 检查按键去抖动（Debounce）模块的下降沿检测逻辑，确保在按键按下瞬间能产生单个时钟周期的平滑高电平脉冲。
  2. 检查控制状态机（FSM），确认其是否根据按键脉冲正确进行状态循环跳转（如 $V_{pp}$ 从 $100\text{ mV}$ 步进加至 $1000\text{ mV}$）。
