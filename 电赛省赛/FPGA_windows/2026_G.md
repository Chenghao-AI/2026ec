### WSL 调起 Windows 程序的 4 个细节

1. **必须用 `cmd.exe /c "..."`**，不能直接 `/mnt/c/.../vivado.bat`——后者会因 Windows 端的 `$PATH` 缺失、绝对路径里有空格、UNC 路径限制而失败。已验证：

   ```bash
   # → Vivado v2019.1 (64-bit)  SW Build 2552052 on Fri May 24 14:49:42 MDT 2019
   ```

2. **路径里有中文 / 空格** 没问题，但**不能**用 UNC（`\\wsl.localhost\...`）当工作目录——`cmd.exe` 不接受。建议：工作目录放在 `/mnt/c/Users/.../FPGA练习_windows端/Vivado/prj_xxx`，这是真实 Windows 路径。

## 仪器支持

实验室中有四台仪器支持，涵盖了信号发生、信号观测、数值测量以及电路供电四大核心环节。以下为每台仪器的**主要功能**与**基本使用方法**。

### 第一台：泰克 Tektronix AFG31102 任意波形/函数发生器

#### **主要功能**

这是一款双通道的任意波形与函数发生器（AFG），其最大输出频率为 **100 MHz**，采样率为 **1 GS/s**。

* **产生标准波形**：可生成正弦波（Sine）、方波（Square）、脉冲波（Pulse）、三角波/锯齿波（Ramp）、噪声（Noise）和直流（DC）信号。
* **产生任意波形（Arb）**：用户可以通过编辑或导入特定的数学公式/数据，生成自定义的非标准波形。
* **信号调制与扫描**：支持幅频调制（AM、FM、PM、FSK、PWM等）、频率扫频（Sweep）以及突发模式（Burst，用于输出特定周期数量的波形）。
* **用途**：用于给待测电路提供输入激励信号。

####   基本使用方法

1. **开机**：按下左下角的电源按钮。
2. **选择波形**：在中间的 **BASIC MODE（基本模式）** 区域内，按下对应的波形按键（例如 `Sine` 正弦波、`Square` 方波、`Pulse` 脉冲波）。
3. **设置参数**：
   * 按下屏幕右侧偏下方的 `Frequency/Period`（频率/周期）按键，然后通过右侧的数字键盘、方向键或旋钮输入目标频率，最后按下对应的单位键（如 `kHz`、`MHz`）确认。
   * 同理，按下 `Amplitude/High`（幅度/高电平）设置信号幅度；按下 `Offset/Low`（偏置/低电平）设置直流偏置。
4. **连接输出**：将 BNC 电缆连接到下方的 `Ch1 Output` 或 `Ch2 Output` 接口。
5. **开启输出**：按下通道上方对应的黄色或蓝色 `On` 按键（灯亮起表示输出激活），此时物理端口开始输出电信号。

### 第二台：泰克 Tektronix MDO32 混合域示波器

#### **主要功能**

这是一款 **3 系列混合域示波器（MDO）**，带宽为 **500 MHz**，采样率为 **2.5 GS/s**。

* **时域分析（示波器）**：通过模拟通道（通道1、通道2）实时捕捉并显示电压随时间变化的波形。
* **频域分析（频谱仪）**：带有专用的 **RF** 射频输入端口，可用于观察信号的频谱（如频率分量、功率等）。
* **混合信号/数电分析**：支持数字通道（Digital Input），用于观测多路逻辑信号。
* **用途**：用于观测、测量和分析电路中各节点的电信号。

#### **基本使用方法**

1. **连接探头**：将示波器探头连接到下方的输入端口（例如通道 `1`）。将探头的接地夹接到电路板的地线（GND），探针接触需要测量的信号点。
2. **校准探头（选做）**：首次使用时，可将探头挂在右下角的 `Probe Comp`（探头补偿，2.5V 1kHz）金属片上，确保示波器显示的方波平整无过冲。
3. **自动设置（最快捷的起步方式）**：按下右下角的 `Autoset` 键，示波器会自动调整垂直档位、水平时基和触发电平，使波形稳定呈现在屏幕上。
4. **手动调节（核心操作）**：
   * **垂直控制（Vertical）**：使用 `Scale` 旋钮调节波形上下拉伸（每格代表的电压值，如 1V/div）；使用 `Position` 旋钮移动波形上下位置。
   * **水平控制（Horizontal）**：使用 `Scale` 旋钮调节波形左右展开或压缩（时间轴，如 100μs/div）；使用 `Position` 旋钮左右平移时间。
   * **触发控制（Trigger）**：通过调节 `Level`（触发电平）旋钮使波形稳定，不发生左右抖动。
5. **数据测量**：可通过触控屏或菜单选择 “Measure” 功能，自动测量频率、峰峰值（Vpp）、均方根（RMS）等参数。
6. **暂停/捕获**：按下右上角的 `Run/Stop`（运行/停止）可冻结波形，或按 `Single/Seq` 捕获单次瞬态信号。

### 第三台：福禄克 Fluke 45 双显示万用表

#### **主要功能**

这是一款高精度的台式五位半数字万用表。其最大的特色在于**双显示（Dual Display）**，能同时在屏幕上显示两种相关的测量数据（例如同时显示交流电压和该电压的频率）。

* **基本测量**：测量交直流电压（V）、交直流电流（A）、电阻（$\Omega$）、频率（FREQ）、二极管测试和通路蜂鸣测试（$\rightarrow| \bullet)))$）。
* **高级功能**：dB 功率测量、读数保持（HOLD）、最大/最小值记录（MN MX）、比较（COMP）等。

#### **基本使用方法**

1. **开机**：按下右下角的绿色 `POWER` 开关。
2. **插表笔**：
   * 黑色表笔始终插在左侧的 `COM`（公共端）插孔。
   * 红色表笔根据测量类型插入相应插孔：
     * 测电压、电阻、二极管、通断：插在 `V $\Omega$ $\rightarrow|$` 插孔。
     * 测微弱电流（100mA以内）：插在 `100 mA` 插孔（内有保险丝保护）。
     * 测大电流（最大10A）：插在 `10A` 插孔。
3. **选择测量功能**：
   * 测直流电压按 `V =--`，测交流电压按 `V ~`。
   * 测电阻按 `$\Omega$`。
   * 测通路（蜂鸣）或二极管按 `$\rightarrow| \bullet)))$` 键。
4. **读取数据**：将表笔接触待测点，屏幕将显示高精度读数。如果需要开启双显示（例如同时看交流电压和频率），可以先按 `V ~` 测量电压，再按下 `2ND` 键（第二显示），接着按 `FREQ` 键，副显示屏就会同步显示频率。

### 第四台：吉时利 Keithley 2231A-30-3 三通道直流电源

#### **主要功能**

这是一款可编程的多通道直流稳压电源，能够为电路板或器件提供稳定的直流电能。它拥有三个独立输出的通道：

* **CH1（通道1）**：输出范围 0 ~ 30V，最大电流 3A。
* **CH2（通道2）**：输出范围 0 ~ 30V，最大电流 3A。
* **CH3（通道3）**：输出范围 0 ~ 5V，最大电流 3A（常用于给 5V 或 3.3V 的数字芯片供电）。

#### **基本使用方法**

1. **开机**：按下左下角的绿色 `Power` 按钮。
2. **选择通道**：按下 `SELECT` 区域下的 `CH1`、`CH2` 或 `CH3` 键，屏幕将切换到对应通道的控制界面。
3. **设定电压（V-Set）和电流限制值（I-Set）**：
   * **设电压**：按下 `V-Set` 键，利用中间的数字键盘直接输入所需的电压值（例如输入 `5` ），然后按下 `Enter` 键确认。或者也可以通过右上角的大旋钮或方向键来进行微调。
   * **设限制电流**：为了防止电路短路烧毁，通常需要设置一个安全的电流限值。按下 `I-Set` 键，输入电流值（例如 `0.5` 表示 500mA 限流），然后按 `Enter` 键。
4. **接线**：使用香蕉头导线，将红线接入选定通道的正极（红孔 `+`），黑线接入负极（黑孔 `-`），并连接到待测电路的电源输入端。
5. **开启输出**：按下中央下方的 `On/Off` 键（灯亮起）。此时电源开始向外供电，屏幕会实时显示当前的输出电压和电路实际消耗的电流。

#### 利用ILA实现高精度频谱图的电脑显示

> **目标**（按你 8 月 1 日截止前的渐进路线，第 1 步）：用 FPGA 对 ADC CHA 接收到的模拟信号进行**频谱分析**，把每个频点的"幅度（mV）"以 ILA 探针波形推到 Vivado 上观察，使得 ILA 上"原先是时域波形"现在变成"清晰的频谱幅度条"。**仅使用 CHA**——CHB 整链路在 Verilog 中删除、引脚不再约束。
>
> **适用范围 / 验收指标**（与 [G题_周期信号测量分析装置.pdf](G题_周期信号测量分析装置.pdf) 严格对照）：
> - **频率分辨率**：Δf = **488.28125 Hz** < 500 Hz 严控 ✓（fs=4 MHz, N=8192）
> - **基频读出误差**：±Δf/2 = ±244 Hz < 题目 1 kHz ✓
> - **幅值精度**：Vpp / RMS / 频谱分量 ≤ **5 mV**（12-bit ADC + Hann 窗 + 比例因子校准）
> - **频率范围**：0 ~ 2 MHz（奈奎斯特），覆盖 ua 10k ~ 200kHz + 4 次谐波 800 kHz + ub 10k ~ 500kHz + 1 MHz 干扰
> - **启动→结果**：单帧 8192 / 4 MHz = **2.048 ms**（远低于题目 2 秒）
>

##### 1. 设计总览与数据流

**核心思想**：FPGA 50 MHz 板载时钟经 MMCM 派 8 MHz，再经 1 级 2 分频 + BUFG 得 **4 MHz 采样时钟**（fs=4 MHz），对 AD9226 ADC CHA 输入信号 4 MSPS 采样；FPGA 内部用 **Xilinx Pipelined Streaming FFT 8192 IP**（N=8192, Δf=488.28 Hz, **16-bit 定点 Scaled 模式**）做频谱估计；每帧 8192 sample 在 2.048 ms 内完成 FFT，**输出 32-bit 总线（[15:0]=Re 16-bit, [31:16]=Im 16-bit）**；**32-bit 总线直接连**到 **CORDIC IP v6.0 Translate 模式**（Input Width=16, Output Width=16），**自动算 |M| 输出 16-bit Mag**；每帧循环输出 4097 bin 单边谱（含 0 和 Nyquist），把其中 0~2 MHz 范围内的 **4096 bin**（Nyquist 边界除外）打包为 (bin, mag) 流送入 ILA；MATLAB 侧仅做离线视觉验证。

> **为什么改用 FFT IP 而不是 2560 个并行 Goertzel**（否定初版致命错误）：
> - **资源**：2560 个并行 Goertzel 在 XC7Z020（53 K LUT / 106 K FF / 220 DSP）**资源暴 700%**，物理不可实现。
> - **Xilinx FFT IP 8192 点 Pipelined Streaming** 实测资源：LUT 5021, FF 9509, DSP 50, BRAM 67，**完全在 7 系列范围内**。
> - **FFT 数值稳定性**：Pipelined Streaming 内置 bit-reverse 排序 + scaling，连帧处理稳定。
> - **频率误差**：基频读出误差 ±Δf/2 ≈ ±244 Hz < 题目 1 kHz ✓。


##### 2. 关键算法：FFT 频谱分析

**原理**（数学公式，仅出现在注释里，代码中调用 Xilinx FFT IP）：

```
对 N 点 FFT：
    X(k) = Σ_{n=0}^{N-1} x(n) · e^{-j2πkn/N}  (k = 0..N-1)

幅值（单边谱）：
    |X(k)| = sqrt(Re² + Im²)  (k = 0..N/2)
    0~fs/2 范围共 N/2+1 = 4097 bin (k = 0..4096)
    题目关心 0~1.25 MHz → 1250 kHz / 488.28 Hz ≈ 2560 bin
    1 MHz 干扰 → 1024 kHz / 488.28 ≈ 2097 bin, 包入 0~4096

频率分辨率（本方案）：
    Δf = fs / N = 4 MHz / 8192 = 488.28125 Hz  < 500 Hz 严格达标 ✓
```

> **为什么 Δf = 488.28 Hz 严格达标**（修正初版 610 Hz 超标）：
> - 初版 fs=5 MHz, N=8192 → Δf=610.35 Hz > 500 Hz 严控 22%
> - **本方案 fs=4 MHz, N=8192 → Δf=488.28125 Hz < 500 Hz 严格 ✓**
> - 4 MHz 整数分频来自 50 MHz / X，X 须 = 12.5（分数分频）
> - **解决**：MMCM 派 8 MHz + 1 级 2 分频 + BUFG = 4 MHz

**Pipelined Streaming FFT 工作机制**：

- **输入**：32-bit 定点复数（实数 16-bit 在 `[15:0]`，虚部 16-bit 补 0 在 `[31:16]`），每周期 1 个 sample；
- **内部**：13 级 Radix-2 蝶形，每级 1 DSP + 块存储，**流水线并行**；
- **输出**：**Scaled 模式下输出位宽自动锁定 = 输入位宽 = 16-bit**（PG109 / DS260 规范），总线 32-bit：
  - `[15:0]` = 16-bit Re（实部）
  - `[31:16]` = 16-bit Im（虚部）
- **自然顺序**（已内置 bit-reverse 排序），每周期 1 个 bin 连续输出；
- **资源**（XC7K70T 同系列参考）：LUT 5021, FF 9509, DSP 50, BRAM 67。

**FFT 配置参数**（Vivado IP GUI，详见 §12 速查表）：

| 参数 | 值 | 说明 |
|------|------|------|
| Transform Length | **8192** | 2^13 |
| Architecture Choice | **Pipelined, Streaming I/O** | 连续帧处理 |
| Run Time Configurable Transform Length | **No** | 固化配置 |
| Data Format | **Fixed Point** | 16-bit 数据 |
| **Input Data Width** | **16** | 加窗后 16-bit |
| **Output Data Width** | **16** | **Scaled 模式 = 输入位宽** |
| Phase Factor Width | **24** | 24-bit 旋转因子 |
| Scaling Options | **Scaled** | 防溢出，输出位宽 = 输入位宽 |
| Rounding Modes | **Convergent Rounding** | 最小化偏差 |
| Output Ordering | **Natural Order** | 内置 bit-reverse 排序 |

**AXI-Stream 握手信号**（**全部修正完毕**）：
- **`s_axis_config_tvalid = 1'b1` 常置**
- **`s_axis_config_tdata[7:0] = 8'b0000_0001`**（bit[0]=1 Forward, bit[1]=0 关闭 IFFT）
- `s_axis_config_tready` = `1'b1`
- `s_axis_data_tvalid` 高电平：当 `frame_buf_ready == 1` 时输出
- **`s_axis_data_tdata[31:0]` = `{16'd0, data_rd}`**（32-bit：Re 16 + Im 16=0）
- **`s_axis_data_tlast` = (sample_cnt == 13'd8191) && s_axis_data_tvalid**
- **`s_axis_data_tready`** = `1'b1`（FFT IP 始终准备好接收）
- `m_axis_data_tdata[31:0]` = **32-bit**：`[15:0]` = 16-bit Re，`[31:16]` = 16-bit Im
- `m_axis_data_tvalid` = FFT IP 内置信号
- `m_axis_data_tlast` = FFT IP 帧末
- `m_axis_data_tready` = `1'b1`（CORDIC 始终准备好接收）

**加窗（汉宁 / Hann）**：

- 8192 项 Hann 窗系数 `w[n] = 0.5(1 − cos(2π n/(N−1)))`，预计算为 **12-bit Q0.12**（范围 0~4095），存于 `HannTable` BRAM；
- **修正符号 bug**：`$signed({1'b0, w_reg})` 强制 13-bit 正数；
- **修正输入打拍对齐**：`x_in_d1` 1 拍延迟与 BRAM 读出的 `w_reg` 时间同步；
- **修正位宽**：24-bit 乘法 → 算术右移 12 位 → 16-bit Q1.15。

**AD9226 偏移二进制转补码**：

- AD9226 datasheet：默认输出**偏移二进制（offset binary, 0~4095, 2048=0V）**；
- **数学等价**：**2's complement = offset binary MSB 取反**（`{~adc_raw[11], adc_raw[10:0]}`）；
- 在 `AdcChaCapture` 中执行。

**幅值（**修正：CORDIC IP v6.0 Translate 模式**）**：

> **上一版错误**：用 CORDIC Square Root 模式 + 24-bit 位宽，与 FFT IP 实际 16-bit 输出位宽不匹配。
>
> **本版修正**：用 CORDIC **Translate 模式（Cartesian → Polar）+ 16-bit 位宽**：
> - **输入**：`s_axis_cartesian_tdata[31:0]` = `{16'd0, Re_16bit, Im_16bit}` 或**直接直连 FFT 32-bit 总线**
> - **内部**：CORDIC 算法旋转 (X,Y) 直到 Y=0，输出 `Zi * Mag(X, Y)`
> - **启用 Compensation Scaling**（默认）：自动乘 `1/Zi` 给出**真实模值**
> - **输出**：`mag_out_tdata` = **16-bit Mag**（1QN 格式）
> - **优势**：**0 DSP 消耗**（纯 LUT CORDIC），**16-bit 位宽与 FFT 输出严格对齐**，直接对接 FFT IP 32-bit Re/Im 复数总线

**CORDIC IP v6.0 GUI 配置**（详见 §12 速查表）：

| Pipelined Mode | **Maximum** | 最大流水线吞吐 |
| **Input Width** | **16** | 16-bit signed Re/Im |

CORDIC 延迟约 24 周期 = 6 μs @ 4 MHz，**远低于 2.048 ms 帧间隔**。

```verilog
module AdcChaCapture (
    input  wire         clk_4m,
    input  wire [11:0]  data_raw,
    input  wire         ora_raw,
    output wire signed [11:0] data_out,
    output wire         ora_out

            adc_pipe[i] <= adc_pipe[i-1];
            ora_pipe[i] <= ora_pipe[i-1];
        end
```

**`PreMul_Hann` 完整代码**（3 级流水）：

```verilog
module PreMul_Hann (
    input  wire        clk, input wire rst,
    input  wire [11:0] x_in, input wire [12:0] idx,
    output wire [15:0] x_hanned_16b
);
    // ✅ Stage 1: BRAM 读 Hann 系数 + 输入数据打 1 拍对齐
    reg [11:0] w_reg;
    reg signed [11:0] x_in_d1;
    always @(posedge clk) begin
        w_reg   <= hann_rom[idx];
        x_in_d1 <= x_in;
    end

    // ✅ Stage 2: 12×12 乘法 → 24-bit
    wire signed [23:0] mul_raw = $signed(x_in_d1) * $signed({1'b0, w_reg});
    reg signed [23:0] mul_r;
    always @(posedge clk) mul_r <= mul_raw;

    // ✅ Stage 3: 24-bit 算术右移 12 位 → 16-bit Q1.15
    reg signed [15:0] x_hanned_r;
    always @(posedge clk) x_hanned_r <= mul_r >>> 12;

    assign x_hanned_16b = x_hanned_r;
endmodule
```

**`FrameBuf_FFT_Driver` 完整正确代码**（**修正** `tlast` + **`s_axis_config`** 强制 FWD + **32-bit `s_axis_data_tdata`** + **`frame_full` 循环清零** + **删除死锁条件** + **端口补 `s_axis_data_tready`**）：

```verilog
module FrameBuf_FFT_Driver (
    input  wire        clk,
    input  wire        rst,
    input  wire [15:0] x_hanned_in,         // 16-bit signed Q1.15 from PreMul_Hann
    // FFT IP 数据输入通道 (AXI-Stream)
    output wire [31:0] s_axis_data_tdata,   // 32-bit (实部16 + 虚部16)
    output wire        s_axis_data_tvalid,  // AXI-Stream valid
    output wire        s_axis_data_tlast,   // 帧末信号
    input  wire        s_axis_data_tready,  // 来自 FFT IP 的 ready 握手信号
    // FFT IP 配置通道 (AXI-Stream)
    output wire [7:0]  s_axis_config_tdata, // 配置总线 (8'b0000_0001 代表 Forward)
    output wire        s_axis_config_tvalid,// 配置使能
    output wire        frame_end_out
);
    // 1. 配置通道：上电常高使能，强制配置为正向 FFT
    assign s_axis_config_tdata  = 8'b0000_0001;
    assign s_axis_config_tvalid = 1'b1;

    // 内部 8192 深度 BRAM
    (* ram_style = "block" *) reg [15:0] buf_ram [0:8191];
    reg [12:0] wr_addr;
    reg [12:0] rd_addr;
    reg        wr_en;
    reg        frame_full;  // 1: 正在读出推给 FFT; 0: 正在写入采样
    reg        frame_end_r;

    // 2. 写控制 (采样写入状态机，删除无用条件)
    always @(posedge clk) begin
        if (rst) begin
            wr_addr    <= 0;
            wr_en      <= 1;        // 复位后直接使能采样
            frame_full <= 0;
        end else if (wr_en) begin
            buf_ram[wr_addr] <= x_hanned_in;
            if (wr_addr == 13'd8191) begin
                wr_addr    <= 0;
                frame_full <= 1;   // 采样满 8192 点，切到读模式
                wr_en      <= 0;
            end else begin
                wr_addr <= wr_addr + 1;
            end
        end else if (!frame_full) begin // ✅ 简化逻辑: 读完释放后重新使能写
            wr_en <= 1;
        end
    end

    // 3. 读控制 (推数据给 FFT IP)
    always @(posedge clk) begin
        if (rst) begin
            rd_addr    <= 0;
            frame_full <= 0;
        end else if (frame_full && s_axis_data_tready) begin
            if (rd_addr == 13'd8191) begin
                rd_addr    <= 0;
                frame_full <= 0; // 读完最后一点，清零 frame_full，启动下一帧采样
            end else begin
                rd_addr <= rd_addr + 1;
            end
        end
    end

    // 4. 打包 AXI-Stream 数据线
    assign s_axis_data_tdata  = {16'd0, buf_ram[rd_addr]}; // 高 16 位虚部补 0
    assign s_axis_data_tvalid = frame_full;
    assign s_axis_data_tlast  = (rd_addr == 13'd8191) && frame_full;

    // 5. 帧末脉冲指示
    always @(posedge clk) begin
        frame_end_r <= s_axis_data_tlast && s_axis_data_tready;
    end
    assign frame_end_out = frame_end_r;
endmodule
```

```verilog
        .frame_end_out        (frame_end_out)
    );

    // 3. FFT IP (xfft_0)
    wire [31:0] fft_m_tdata; // 16-bit Re [15:0] + 16-bit Im [31:16]
    wire        fft_m_tvalid, fft_m_tlast, fft_m_tready;
    wire [11:0] fft_m_user;  // bin 索引 (0~4095)

    xfft_0 u_fft (
        .aclk                        (io_clk_4m),
        .s_axis_config_tdata         (fft_cfg_tdata),
        .s_axis_config_tvalid        (fft_cfg_tvalid),
        .s_axis_config_tready        (/* open */),
        .s_axis_data_tdata           (fft_s_tdata),
        .s_axis_data_tvalid          (fft_s_tvalid),
        .s_axis_data_tready          (fft_s_tready),
        .s_axis_data_tlast           (fft_s_tlast),
        .m_axis_data_tdata           (fft_m_tdata),     // 32-bit 输出
        .m_axis_data_tvalid          (fft_m_tvalid),
        .m_axis_data_tready          (fft_m_tready),
        .m_axis_data_tlast           (fft_m_tlast),
        .m_axis_data_tuser           (fft_m_user)
    );

    // 4. CORDIC IP (cordic_0, Translate 模式)
    wire [15:0] cordic_mag_tdata; // 16-bit Mag
    wire        cordic_mag_tvalid, cordic_mag_tlast, cordic_mag_tready;

    cordic_0 u_cordic (
        .aclk                        (io_clk_4m),
        .s_axis_cartesian_tdata      (fft_m_tdata),     // 32-bit 100% 直连
        .s_axis_cartesian_tvalid     (fft_m_tvalid),
        .s_axis_cartesian_tready     (fft_m_tready),
        .s_axis_cartesian_tlast      (fft_m_tlast),
        .m_axis_dout_tdata           (cordic_mag_tdata),// 16-bit Mag
        .m_axis_dout_tvalid          (cordic_mag_tvalid),
        .m_axis_dout_tready          (cordic_mag_tready),
        .m_axis_dout_tlast           (cordic_mag_tlast)
    );

    assign cordic_mag_tready = 1'b1;

    // 5. BinSelect 过滤输出前 2560 个频点
    wire [23:0] mag_24;
    wire [11:0] bin_12;
    wire        mag_valid;

    BinSelect u_binsel (
        .clk                         (io_clk_4m),
        .rst                         (rst),
        .mag_in                      ({8'd0, cordic_mag_tdata}),
        .bin_in                      (fft_m_user),      // ✅ 修正: 正确传入 FFT 输出的 bin 索引信号
        .mag_in_valid                (cordic_mag_tvalid),
        .mag_out                     (mag_24),
        .bin_out                     (bin_12),
        .valid_out                   (mag_valid)
    );

    assign io_probe_mag       = cordic_mag_tdata;
    assign io_probe_bin       = bin_12;
    assign io_probe_valid     = mag_valid;
    assign io_probe_adc       = io_adc_a_data;
    assign io_probe_frame_end = frame_end_out;
endmodule
```

**`BinSelect` 框架**：

```verilog
module BinSelect (
    input  wire        clk,
    input  wire        rst,
    input  wire [23:0] mag_in,
    input  wire [11:0] bin_in,
    input  wire        mag_in_valid,
    output reg  [23:0] mag_out,
    output reg  [11:0] bin_out,
    output reg         valid_out
);
    always @(posedge clk) begin
        if (rst) begin
            valid_out <= 1'b0;
            mag_out   <= 24'd0;
            bin_out   <= 12'd0;
        end else if (mag_in_valid && (bin_in < 12'd2560)) begin
            mag_out   <= mag_in;
            bin_out   <= bin_in;
            valid_out <= 1'b1;
        end else begin
            valid_out <= 1'b0; // ✅ 超出 2560 范围拉低有效信号
        end
    end
endmodule
```

##### 5. 频率精度 / 幅度精度如何保证

**频率精度**（题目硬要求 Δf ≤ 500 Hz, 基频误差 ≤ 1 kHz）：
- 本方案 Δf = **4 MHz / 8192 = 488.28125 Hz < 500 Hz 严格达标** ✓
- **基频读出误差 = ±Δf/2 = ±244 Hz < 题目 1 kHz ✓**
- **Nyquist 频率 2 MHz** 覆盖 1 MHz 干扰 + 4 次谐波 800 kHz

**幅度精度**（≤ 5 mV）：
- 链路：
  - AD9226 offset binary 0~4095 → MSB 取反 → 2's complement -2048..+2047
  - 加窗 → x_hanned_16b (Q1.15) 送 FFT IP
  - FFT 输出 (16-bit Re, 16-bit Im)
  - CORDIC Translate 16-bit → 16-bit Mag
- **加窗（Hann）**：8192 项 Hann 窗，系数预计算为 12-bit；
- **幅值校准**：用一次正弦标准源标定比例因子 `k_scale = 实际_mV / 观测_LSB`；
- **频谱泄漏**：Hann 窗后泄漏到邻 bin ≤ −31 dB。

**矫正思路**（亚 bin 精度）：MATLAB 离线阶段 parabola 拟合提高 10× 精度。
