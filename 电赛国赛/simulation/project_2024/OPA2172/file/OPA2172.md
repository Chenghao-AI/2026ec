**第 5~6 页 — Pin Configuration and Functions（引脚定义）**

- **为什么重要**：洞洞板搭电路，接错引脚 = 芯片烧毁。最不能出错的一页。

- OPA2172 是双运放

  （2 个独立运放 A 和 B 集成在 1 个芯片里），8 脚封装：

  - SOIC-8（D 封装）/ VSSOP-8（DGK 封装）/ WSON-8（DRG 封装）

     的引脚：

    - Pin 1：**+IN(A)**（运放 A 同相输入）
    - Pin 2：**-IN(A)**（运放 A 反相输入）
    - Pin 3：**OUT(A)**（运放 A 输出）
    - Pin 4：**V-**（负电源，共用）
    - Pin 5：**+IN(B)**（运放 B 同相输入）
    - Pin 6：**-IN(B)**（运放 B 反相输入）
    - Pin 7：**OUT(B)**（运放 B 输出）

## 五、OPA2172 在比赛中的典型应用场景

基于 OPA2172 的特性（高压 36V + 精密漂移 1.5 μV/°C + 10 MHz + RRO + 无相位反转 + EMI 抗扰），它在比赛中最适合：

1. **工业传感器信号调理**：高压供电（36V）+ 低漂移（1.5 μV/°C）+ 无相位反转，适合 4~20 mA 环路、热电偶、RTD 等工业传感器信号的前置放大
2. **高压信号处理**：供电最高 36V，可以处理高压信号（如工业 4~20 mA 环路的高边检测、高压传感器信号调理）
3. **EMI 干扰环境下的精密放大**：内置 EMI 滤波，在比赛现场（可能有开关电源、数字电路干扰）比 OPA333/OPA376 更抗干扰
4. **大信号输入场景**：无相位反转保护，当输入共模电压超出范围时输出不会反相，适合大信号输入的应用
5. **容性负载驱动**：串联 50 Ω 隔离电阻可稳定驱动容性负载（如长电缆、ADC 采样电容）
