## 二、逐页精析：看 / 查 / 跳 三级分类

### 🔴 必须赛前精读

**第 1 页 — Features / Description**

- **为什么重要**：30 秒判断"这颗功放能不能满足题目功率要求"。
- 关键信息：
  - **2 W 输出**（4 Ω 负载、5 V 供电、10% THD+N 条件下）→ 题目若要求"≥1 W 音频输出"，它够用；若要求 5 W、10 W，直接换芯片（如 TPA31xx 系列）
  - **Filterless（无滤波器）**→ 省掉 LC 输出滤波，洞洞板上外围元件极少；代价是 EMI 要靠系统层面处理
  - **增益引脚可选 6/12/18/23.5 dB** → 增益不用算电阻，查表接电平即可（换算：6 dB≈2 倍、12 dB≈4 倍、18 dB≈8 倍、23.5 dB≈15 倍）
  - **效率 ~90%** → 几乎不发热，洞洞板不用考虑大散热片
  - **depop + 短路/过热保护** → 赛场接错线时有保命能力
- **比赛策略**：先确认三件事——功率够不够（2 W）、负载阻抗允不允许（≥4 Ω 扬声器）、供电对不对（单 5 V）。

**第 3 页 — Pin Configuration and Functions（引脚图 + 引脚功能表）🏆 本书最不能出错的一页**

- 引脚按功能分四组（具体脚号以引脚图 Top View 为准，截图存手机）：

  - **INP / INN**：差分模拟输入，高阻 CMOS 输入，**可作求和节点**（意味着可以把两路信号用电阻求和后送进来，这是隐藏考点）
  - **GAIN0 / GAIN1**：增益配置引脚，按表接 GND 或 VDD → 决定 6/12/18/23.5 dB
  - **SHUTDOWN**：关断控制脚（注意有效电平，正常工作时要用上拉/下拉电阻固定在有效电平，**悬空可能导致芯片不工作**）
  - **OUTP / OUTN**：BTL 桥接输出，**扬声器接在这两脚之间**
  - **VDD / GND(PGND)**：单 5 V 供电；功率地和信号地引脚可能有多个

- 比赛策略（D 类功放三大接线铁律）

  ：

  1. **扬声器跨接 OUTP–OUTN，任何一端都不能接地、也不能对地接电容**（BTL 与单端功放的本质区别，接错=烧输出级）；
  2. **GAIN0/GAIN1 必须明确接电平**，赛前把增益配置表背下来；
  3. **SHUTDOWN 脚接对电平**，调试时"没声音"第一个查它。

**第 4 页 — Absolute Maximum Ratings + Recommended Operating Conditions**

- 关键限值：
  - **VDD：推荐 4.5~5.5 V**（绝对最大约 6 V）→ **这颗芯片最怕的就是接错电源**。赛场上运放常用 ±12 V/±15 V 电源轨，把 12 V 灌进 VDD 必烧无疑。务必单独用 5 V 轨供电
  - 输入引脚电压不能超过 VDD+0.3 V → 前级运放若用 ±12 V 供电，**必须先衰减/限幅再进 TPA2000D1**
  - 结温 150°C，有过热保护
- **比赛策略**：把"TPA2000D1 = 单 5 V"写在洞洞板电源分配表的醒目位置。

**第 5 页 — Electrical Characteristics（电气特性表）🏆 取值权威来源**

- 必须逐行看懂的字段：
  - **输出功率 vs 负载 vs 供电**：4 Ω/8 Ω 下各能出多少 W（决定音量上限）
  - **THD+N**：典型值及测试条件（1 kHz、某功率下）→ 音频质量指标
  - **SNR / 输出噪声**：底噪水平
  - **PSRR**：电源抑制比 → 决定 5 V 电源要多干净（D 类对电源纹波敏感，去耦要认真做）
  - **ICC（静态电流）/ ICC(shutdown)**：电池供电题目的续航计算依据
  - **增益误差、输入阻抗**：与前级匹配
- **比赛策略**：和运放手册不同，这里**没有 VOS/IB/CMRR/GBW 那些东西**——功放手册的电气特性表围绕"功率、失真、效率、电源"展开。取数做两件事：① 核算题目要求的输出功率下 THD+N 是否达标；② 核算输入信号幅度与增益档位是否匹配（例：23.5 dB≈15 倍时，满输出 2 W/4 Ω 对应差分输出峰值约 4 V，所需输入峰值仅约 0.27 V，前级别给太大）。

**第 10~11 页 — Detailed Description（功能框图 + 特性描述）**

- 功能框图：差分输入级 → 增益选择 → D 类调制器 → BTL 输出级。理解"增益在芯片内部已定，外部不设反馈电阻"
- **增益配置表（GAIN1/GAIN0 电平组合 → 6/12/18/23.5 dB）** → 背下来
- **Shutdown 与 depop 时序**：上电/关断时芯片内部按序动作以抑制"噗"声；比赛时若题目要求"无开关机冲击"，按手册时序操作 SHUTDOWN 脚
- **保护行为**：短路（对电池/对地/对负载）与过热的触发与恢复方式（自动恢复 or 锁存）→ 调试时输出突然没了，先想到保护触发
- **Filterless 原理与 EMI 说明**：靠扬声器线圈电感+人耳/系统完成"滤波"；**扬声器引线较长时建议加磁珠（ferrite bead）或简单 LC 抑制 EMI**——洞洞板上喇叭线往往很长，这条要记住

**第 12~15 页 — Application and Implementation（典型应用电路）🏆 洞洞板直接照抄**

- 典型应用图包含全部外围：
  - **输入耦合电容 + 偏置网络**（单端信号源 → 差分输入的转换方式，这是最容易设计错的部分，直接抄图中结构和容值）
  - **VDD 去耦**：小陶瓷电容（0.1 µF 级）紧贴引脚 + 大电解（百 µF 级）作储能——D 类输出级是开关电流负载，**大去耦电容比运放电路更重要**
  - **SHUTDOWN 脚偏置电阻**
  - **BTL 扬声器接法**
- 设计步骤文字：输入电容决定低频截止点（f = 1/2πRC 关系）、去耦电容选型、扬声器阻抗选择
- **比赛策略**：这 2~3 页是"抄板区"。赛前把典型应用图手绘一遍，记住每个外围元件的**作用**（耦合/偏置/去耦/配置），赛场上即使图不在手边也能复现。

**第 15~16 页 — Layout Guidelines / Layout Example**

- 去耦电容紧贴 VDD/GND 引脚；电源与输出走线短而粗；输入弱信号线远离输出开关线；地单点/星形处理
- **比赛策略**：D 类是**开关功率电路**，布局重要性远高于你之前学的任何运放。洞洞板实操：① 去耦电容贴着芯片焊；② 扬声器两根出线绞合或并行走、远离输入级；③ 地线用粗导线/多根并联；④ 输入耦合部分远离输出级。做到这四点，底噪和自激问题基本消失。

| 维度         | 运放（OPA333/LM318 等）     | TPA2000D1 这类 D 类功放                                      |
| ------------ | --------------------------- | ------------------------------------------------------------ |
| 核心设计动作 | 自己设计反馈网络定增益/带宽 | **增益引脚配置，外部无反馈电阻**                             |
| 手册重点页   | 电气特性表（VOS/IB/GBW…）   | **引脚配置表 + 典型应用电路 + 布局**                         |

| 负载接法     | 输出对地接负载              | **负载跨接 OUTP–OUTN（BTL）**                                |
| 最怕的错误   | 接错引脚、超共模范围        | **误接高压电源、输出端接地/对地接电容**                      |
| 布局敏感度   | 中                          | **极高（开关噪声）**                                         |
| 仿真重点     | 环路稳定性、噪声            | 输入匹配/增益/削波点（开关级仿真慢，失真/效率直接查手册曲线） |

## 五、Spice For TI 仿真要点

1. **先仿输入接口**：把"信号源 → 输入耦合/偏置网络 → 芯片输入"搭出来，AC 扫描确认低频截止点和高阻输入不被加载
2. **增益与削波核算**： transient 正弦扫描，逐档增益下看输出何时削波。记住锚点：2 W/4 Ω 对应差分输出 Vrms≈2.83 V（峰值≈4 V），以此定输入幅度上限
3. **不要试图用瞬态仿真"看"D 类失真和效率**：开关级收敛慢、意义小，THD+N 和效率**直接查手册第 6~9 页曲线**，仿真只做线性部分验证
4. **电源去耦敏感性实验**：在 5 V 上叠加纹波源，观察输出纹波，验证去耦电容取值（这能帮你在赛场上快速决定大电容用 100 µF 还是 470 µF）

## 一、一句话本质区别

|              | 运算放大器（Op-Amp）                             | 功率放大器（Power Amp）                            |
| ------------ | ------------------------------------------------ | -------------------------------------------------- |
| **核心任务** | 精确地**处理电压信号**（放大、滤波、运算、调理） | 把信号**变成足够大的功率**去驱动负载（喇叭、电机） |
| **关心什么** | 电压准不准、失真小不小、噪声低不低               | **能输出多少瓦、效率高不高、会不会烧**             |
| **输出能力** | 几 mA ~ 几十 mA，带不动喇叭                      | 几百 mA ~ 几 A，专门干"力气活"                     |

打个比方：**运放是"精密的大脑"，功放是"有力的肌肉"**。大脑负责把信号想清楚、算准确；肌肉负责把它实实在在地推出去。一个管"准"，一个管"猛"。

------

## 二、为什么会有这种分工？——从"能不能带负载"说起

这是理解两者区别的物理根源：

- 运放的输出级很弱

  。它的内部晶体管是为"线性、低噪声、高增益"优化的，输出电流通常只有几 mA。你若把一个 4 Ω 喇叭直接接在运放输出上：

  - 想要 1 W 功率 → 需要约 0.5 A 电流 → 运放根本给不出 → **严重削波 / 发热烧毁**

- **功放的输出级很强**。它的末级是大功率管（或 D 类开关管），专为大电流设计，能轻松输出几百 mA 到几 A。

所以信号链天然是分两段干的：

```
微弱信号 → [运放：电压放大 + 滤波 + 调理] → 中等幅度干净信号 → [功放：功率放大] → 喇叭/电机
            ↑ 精密、低噪声、自己设计反馈              ↑ 大电流、高效率、固定功能
```

**运放负责"把信号做对"，功放负责"把信号做大功率送出去"。** 这就是为什么你的比赛系统里两者经常前后串联出现。

------

## 三、设计哲学的根本不同（这决定了你怎么读手册、怎么搭电路）

这是对你备战**最实用**的一层：

### 运放 = "空白画布"，你自己设计

- 运放本身只是一个

  高开环增益的差分放大单元

  ，它"要变成什么电路"完全由你外接的

  反馈网络

  决定：

  - 接成反相/同相 → 放大器
  - 接 RC → 滤波器
  - 接成积分/微分 → 运算电路

- **增益、带宽、频率响应全是你用电阻电容算出来的**。

- 所以运放手册的重点是**电气特性表**（VOS、IB、GBW、CMRR…），你要拿这些参数自己做环路设计。

### 功放 = "成品黑盒"，你照抄外围

- 功放（尤其 TPA2000D1 这类集成 D 类）内部已经把放大、调制、保护全做死了，**增益是引脚配置好的，不需要你设计反馈电阻**。
- 你要做的只是：**按典型应用图把外围元件焊对**（耦合电容、去耦电容、SHUTDOWN 偏置、扬声器接法）。
- 所以功放手册的重点是**引脚配置表 + 典型应用电路 + 布局指南**，而不是让你算增益。

> 这就是上一轮我强调的"思维切换"：**用运放时你是设计师，用功放时你是装配工+接线员。**

## 四、关键差异对照表（建议背下来）

| 维度       | 运放                       | 功放（以 TPA2000D1 为例）               |
| ---------- | -------------------------- | --------------------------------------- |
| 增益怎么定 | **外接反馈电阻自己算**     | **引脚配置，查表得 6/12/18/23.5 dB**    |
| 输出性质   | 线性模拟电压               | D 类是几百 kHz 的 **PWM 开关波形**      |
| 输出电流   | mA 级                      | A 级                                    |
| 负载接法   | 输出对地接负载             | **BTL：负载跨接两输出端**               |
| 效率       | 不重要（线性，自身也耗电） | **极重要（D 类 ~90%）**                 |
| 最怕的错误 | 超共模范围、相位反转、振荡 | **误接高压电源、输出端接地/对地接电容** |
| 布局敏感度 | 中                         | **极高（开关噪声）**                    |
| 手册重点页 | 电气特性表                 | 引脚图 + 典型应用 + 布局                |
| 仿真重点   | 环路稳定性、噪声           | 输入匹配/削波点（失真效率查曲线）       |

## 五、特别澄清一个常见误区："功放也是放大器，那 LM318 这种高速运放能不能当功放？"

**不能，原因正是上面的"输出电流"。** 哪怕 LM318 压摆率高达 150 V/μs、速度飞快，它的输出电流也只有 ~25 mA，照样带不动 4 Ω 喇叭。"快"和"有力"是两回事：

- **LM318**：能把信号**快速地**放大到十几伏，但电流小 → 适合驱动 ADC、做高速滤波，**不适合推喇叭**
- **TPA2000D1**：速度不快（音频带宽就够），但电流大、效率高 → **专门推喇叭**

判断口诀：**看"输出电流"和"额定功率"这两个数。有"几瓦、几百mA~几A"才是功放；只有"mV失调、MHz带宽、mA输出"的是运放。**

------

## 六、落到你的比赛：信号链怎么分工

电赛模拟题里，一个完整音频/信号系统通常是这样的流水线，**运放和功放各司其职**：

```
传感器/信号源(μV~mV)
   │
   ▼
[运放1：前置放大 + 滤波]   ← OPA333/OPA376（精密、低噪）
   │  把微弱信号放大到 mV~V 级，滤掉干扰
   ▼
[运放2：增益可调 / 均衡 / 混音]  ← OPA4322/LM318（按需选速度）
   │  信号已"做对、做干净"，幅度到 V 级
   ▼
[功放：功率放大]           ← TPA2000D1（单5V，BTL直驱喇叭）
   │  把 V 级信号变成"瓦级功率"
   ▼
  喇叭 / 负载
```

**实操要点**：

1. 运放部分可以用 ±12 V/±15 V 双电源（信号摆幅大、设计灵活）；
2. **进功放前必须确认两件事**：① 信号幅度别超过功放输入允许范围（TPA2000D1 输入不能超 VDD+0.3 V，必要时衰减）；② 功放单独用干净的 **5 V** 供电，**绝不能把运放的 ±12 V 灌进功放 VDD**——这是赛场上烧功放的第一大原因。

------

## 七、总结成三句话

1. **运放处理电压（求"准"），功放输出功率（求"猛"）**——前者带不动喇叭，后者不负责精密调理。
2. **运放是空白画布要你设计反馈，功放是成品黑盒要你照抄外围**——这决定了读手册和搭电路的方式完全不同。
3. **判别看输出电流和额定功率**：mA 级是运放，A 级/瓦级是功放；两者在信号链里前后串联，运放把信号做对，功放把它送出去。
