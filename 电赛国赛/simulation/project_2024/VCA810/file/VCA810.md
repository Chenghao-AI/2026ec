## 二、与 PGA113 的本质区别（先建立认知框架）

在逐页分析之前，你需要先理解 VCA810 和 PGA113 是**完全不同类型**的芯片：

| 对比维度         | PGA113                                       | VCA810                                   |
| ---------------- | -------------------------------------------- | ---------------------------------------- |
| **芯片类型**     | 数字可编程增益放大器（PGA）                  | 压控可变增益放大器（VGA）                |
| **增益控制方式** | SPI 数字接口（MCU 写命令字）                 | 模拟电压控制（Pin 3 加直流电压）         |
| **增益范围**     | 离散档位：1/2/5/10/20/50/100/200             | 连续可调：-40dB ~ +40dB                  |
| **供电方式**     | 单电源 2.2V~5.5V                             | **双电源 ±5V（典型），±4V~±6V**          |
| **引脚数**       | 10 pin（VSSOP-10）                           | **8 pin（SOIC-8）**                      |
| **带宽**         | 随增益变化（G=1 时 10MHz，高增益时急剧下降） | **恒定 35MHz（不随增益变化！）**         |
| **核心应用场景** | ADC 前端信号调理、多量程切换                 | AGC 自动增益控制、可调滤波器、压控振荡器 |

**这意味着：VCA810 不需要写 SPI 驱动代码，但需要 DAC 输出模拟电压来控制增益。比赛时如果你要用 MCU 控制 VCA810 的增益，你需要一个 DAC（或用 PWM+RC 滤波模拟）。**

- 位置：整页文字 + 功能框图（Functional Block Diagram）

- 重要性：

  极高

  。这一页解释了 VCA810 的内部架构：

  - 差分输入级（高阻抗）

  - 内部增益控制放大器

## 五、VCA810 vs PGA113：比赛时的核心差异速记

| 维度             | PGA113                       | VCA810                       |
| ---------------- | ---------------------------- | ---------------------------- |
| **控制方式**     | MCU 通过 SPI 写命令字        | DAC 输出模拟电压到 VC 引脚   |
| **增益调节**     | 离散 8 档                    | 连续 -40dB ~ +40dB           |
| **带宽**         | 随增益变化（高增益时变窄）   | **恒定 35MHz**               |
| **供电**         | 单电源 2.2~5.5V              | **双电源 ±5V**               |
| **引脚复杂度**   | 10 pin，含 SPI 三线          | 8 pin，极简                  |
| **手册重点页数** | ~12 页（SPI 命令占大量篇幅） | ~10 页（应用电路占大量篇幅） |
| **比赛典型用途** | ADC 前端多量程切换           | AGC、压控滤波器、压控振荡器  |

**核心结论**：VCA810 这份 42 页手册中，真正需要精读的约 **8-10 页**（约 25%），大量应用电路（P22-29）是你的"武器库"——比赛题目一旦涉及 AGC、可调滤波器、振荡器等，直接翻到对应页面抄电路。与 PGA113 最大的区别是：**VCA810 不需要写代码控制，但需要一个 DAC 来产生控制电压 VC；而且必须用双电源供电，洞洞板上要准备 ±5V 两路电源。**





这个电路图展示的是 VCA810 在 100MHz 频率下的小信号仿真。它之所以在 100MHz 时还能完美工作，主要有以下三个核心原因。

理解这三点，不仅能帮你弄懂这个例程，对你在电赛中高频电路的设计也极具实战价值：

------

### 1. 破解“35 MHz”的参数误区

你在手册第一页的 Features 里会看到一行字：**“Constant Bandwidth vs Gain: 35 MHz”**。
很多初学者会误以为它的最高工作频率只有 35MHz，其实完全不是这样：

- **35MHz 是它的“最差保底带宽”**：VCA810 是一个压控增益放大器，它的带宽会随着增益（Gain）的增大而减小。35MHz 指的是**当增益开到最大（+40dB，即放大100倍）时**，它的 -3dB 带宽依然能保持在 35MHz 左右（为了保证高增益下的稳定性，内部做了带宽限制）。
- **低增益时的真实带宽高达 120MHz ~ 300MHz**：当增益设置在 **0dB 甚至负增益**（比如衰减信号）时，VCA810 的 -3dB 带宽可以轻松达到 **120MHz 到 300MHz 以上**。
- **结论**：在例程的默认仿真状态下，只要增益没有开到最大（比如设置为 0dB 或更低），100MHz 的信号完全在它的有效通带之内。

------

### 2. 10mV 的微小输入避开了“压摆率”限制

高频电路能否工作，除了看带宽，还要看**压摆率（Slew Rate, SR）**。
VCA810 的压摆率典型值高达 。



- **计算对比**：信号需要的压摆率（$6.28 \text{ V/}\mu\text{s}$）远远小于芯片的极限能力（$350 \text{ V/}\mu\text{s}$）。
- **结论**：因为输入信号非常微弱（只有 $10\text{mV}$），即使频率很高，芯片内部的晶体管也能轻而易举地跟上这个电压变化，完全不会发生波形失真。

------

### 3. 差分输入接法适合高频

注意看图中的接法：信号源 `V5` 的两端分别接到了 VCA810 的 **Pin 1 (+)** 和 **Pin 8 (-)**。

- 这是一种**伪差分（或单端转差分）的输入方式**。
- 在 100MHz 的高频下，相比于单端输入（一端接地，一端接信号），差分输入能够更好地抑制共模干扰和地线噪声，这也是它能稳定工作在百兆赫兹频段的重要电路设计原因。

### 💡 备赛避坑指南（实战经验）

如果你在电赛中使用 VCA810 处理 100MHz 信号，请务必注意：

1. **电源旁路电容不能省**：必须在 Vcc (Pin 6) 和 Vee (Pin 7) 紧贴着引脚的位置放置 **0.1µF (104) 陶瓷电容**并联 **1µF** 的钽电容，否则高频下极易产生自激振荡。
2. **增益控制端（Pin 3）要干净**：Gain 引脚对噪声非常敏感，如果该引脚有杂波，会直接调制到 100MHz 的输出信号上。实际电路中通常需要在此处加一个对地的 RC 低通滤波。
