这个弹窗的意思是：**你当前正在编辑的这张原理图，没有被包含在仿真层次结构中**——简单来说，PSpice 不知道你这张图"归谁管"，不知道该不该仿真它。

------

## 为什么会报这个错？

PSpice for TI 是基于 OrCAD 内核的，它采用**层次化（Hierarchy）**管理方式。一个完整工程的结构是这样的：

```
工程顶层（.opj）
  └── 设计文件夹（Design Folder）
        └── 原理图（.dsn）
              └── 具体某一页（.asc / Page）
```

------

## 最可能的原因 & 解决方法

### 方法一：检查左侧"Project Manager"（项目管理器）

1. 打开 PSpice for TI 后，左侧应该有 **Project 面板**（如果没有，按 `Ctrl+Shift+P` 或菜单栏 View → Project Manager 调出）
2. 在树形目录中展开：
   - 找到你的工程名（类似 `OP07_XXX.opj`）
   - 展开 `Design Resources` → `xxx.dsn` → `SCHEMATIC1`（或类似名称）
3. **右键点击你要仿真的那张原理图页**（比如 `PAGE1`），确认它在列表中存在
4. 然后**右键点击 `.dsn` 文件** → 选择 **"Set as Active Design"**

### 方法二：从正确入口启动仿真

很多新手会犯一个错误：**在没有选中工程的情况下直接点仿真按钮**。正确做法是：

1. 在 Project 面板中，**单击选中你的 `.dsn` 文件**（或 `.opj` 工程名）
2. 然后再点菜单栏的 **PSpice → Run**（或点绿色三角 ▶️ 按钮）
3. 此时弹出的应该是"Simulation Settings"对话框，而不是这个错误

### 方法三：如果是直接打开 `.asc` 文件导致的

如果你是从文件夹里**直接双击打开了 `.asc` 原理图文件**（跳过了工程文件 `.opj`），那么仿真引擎根本无法识别层次关系。

✅ 正确做法：

- 从 **`.opj` 工程文件**打开工程（双击 `.opj` 或用 File → Open → Project）
- 再从左侧 Project 面板中双击打开具体的原理图页

### 方法四：重新建立仿真配置

如果上述方法都不行，可能需要重新配置仿真：

1. 菜单栏 → **PSpice → Edit Simulation Profile**
2. 如果弹出提示说没有 profile，点击 **"Create"** 创建一个新的
3. 设置仿真类型（Time Domain / AC Sweep / DC Sweep 等）
4. 保存后再 Run
