## 二、逐页重要度判定

### 必须精读（比赛时优先翻阅）

**P1 — 首页（Features + Description + 简化原理图）**

- 位置：页面左上 Features 列表、右侧简化原理图
- 重要性：**极高**。Features 列表用 1 分钟就能抓住芯片核心能力：增益范围（PGA113 是 scope gains：1/2/5/10/20/50/100/200）、供电范围（2.2V~5.5V）、SPI 接口、零漂移、2 通道 MUX。右侧的简化原理图直接展示了内部 MUX → 运放 → 输出 的信号流向。**拿到任何 TI 芯片手册，第一页永远是起点。**

**P3 — Device Comparison（第5节，器件对比表）**

- 位置：整页一个表格
- 重要性：**极高**。一张表就能区分 PGA112/113/116/117 四款芯片的差异：PGA113 = 2 通道 MUX + Scope Gains（1,2,5,10,20,50,100,200）+ 无 SPI 菊花链 + VSSOP-10 封装。比赛时如果遇到同系列的其他型号，这张表帮你 30 秒内判断差异。

**P4 — Pin Configuration（第6节，引脚图 + 引脚功能表）**

- 位置：上半部分是 VSSOP-10 封装的顶视图，下半部分是 Pin Functions 表格

- 重要性：**极高**。PGA113 的 VSSOP-10 引脚排列：你需要牢记的关键引脚是 —

  - **AVDD**（模拟电源）、**DVDD**（数字电源）、**GND**
  - **VCAL/CH0** 和 **CH1**（两个模拟输入通道）
  - **VOUT**（输出）
  - **VREF**（参考电压）
  - **CS、SCLK、DIO**（SPI 三线接口，注意 PGA113 没有单独的 DOUT，DIO 是双向的）
  - **ENABLE**（使能/关断控制）

  **洞洞板焊接时，这张图就是你的"地图"。**

**P5 — Absolute Maximum Ratings（第7.1节）**

- 位置：页面上半部分表格

- 重要性：

  极高

  。关键红线：

  - 电源电压 VS = AVDD − GND：最大 7V
  - 模拟输入电压：(GND − 0.5V) ~ (AVDD + 0.5V)
  - 数字输入电压：(GND − 0.5V) ~ (DVDD + 0.5V)
  - 输出短路时间：Continuous
  - **比赛时一旦超过这些值，芯片可能直接烧毁。动手前必须看。**

**P6-8 — Electrical Characteristics（第7.5节，电气特性表）**

- 位置：跨 3 页的密集参数表，测试条件为 VS = AVDD = DVDD = 5V

- 重要性：**高**，但不需要全部记住。你比赛时需要重点关注的参数行：

  - **Offset Voltage（VOS）**：典型 ±10μV，最大 ±25μV — 零漂移的核心卖点
  - **Gain Error**：各增益档的精度
  - **Input Bias Current**：影响高阻抗源时的精度
  - **Output Voltage Swing**：决定了输出能摆到多接近电源轨（Rail-to-Rail 输出能力）
  - **−3dB Bandwidth**（在各增益下）：G=1 时约 10MHz，G=200 时显著降低
  - **Settling Time**（0.1%/0.01%）：切换增益后多久稳定

  **可以忽略的行**：温度漂移的详细温漂系数（除非你的设计对温度极度敏感）、Quiescent Current 的微小变化。

**P9 — SPI Timing（第7.6节）**

- 位置：页面上半部分表格
- 重要性：**高**。SPI 时序参数：SCLK 最大频率、CS setup/hold 时间、数据 setup/hold 时间。写 SPI 驱动代码时这些是关键约束。PGA113 的 SPI 最大时钟约 10MHz（但菊花链模式下降为 ~9MHz）。

**P20 — Detailed Description / Overview（第8.1-8.3节）**

- 位置：整页文字 + 内部框图

- 重要性：

  极高

  。这一页解释了 PGA113 的内部架构：

  - 输入 MUX（2 通道 + CAL 通道）
  - 零漂移斩波运放架构
  - SPI 接口结构
  - Shutdown 模式
  - **VREF 引脚的作用**：当 VREF = GND 时，输出只能正向摆动；当 VREF = AVDD/2 时，输出可以正负双向摆动（交流信号必备）。这是理解电路设计的核心。

**P21 — Table 1: Frequency Response vs Gain（第8.5节）**

- 位置：页面顶部大表格
- 重要性：**极高**。这张表给出了每个增益档位下的：−3dB 带宽、Slew Rate（上升/下降）、0.1% 和 0.01% 建立时间。**PGA113 的 Scope Gains 对应右半列**：G=1 带宽 10MHz，G=200 时明显收窄。比赛选型增益时必须参考此表。

**P22 — SPI Mode Settings（第8.6.1节续）**

- 位置：Table 2（SPI 模式设置）

- 重要性：**高**。PGA113 支持两种 SPI 模式：

  - Mode (0,0)：CPOL=0, CPHA=0 — 时钟空闲低电平，上升沿采样
  - Mode (1,1)：CPOL=1, CPHA=1 — 时钟空闲高电平，上升沿采样

  **写 SPI 配置代码时，这决定了你用哪种 SPI Mode。**

**P29 — SPI Commands（第8.6.4节，Table 3）**

- 位置：页面上半部分，Table 3 专门列出 PGA112/PGA113 的命令格式

- 重要性：**极高，可能是整份手册最核心的一页**。PGA113 的 16-bit SPI 写命令格式：

  - D15-D8 = `00101010`（写命令头）
  - D7-D4 = G3~G0（4 位增益选择码）
  - D3-D0 = CH3~CH0（4 位通道选择码）

  读命令：D15-D8 = `01101010`，D7-D0 = `00000000`

  **没有这张表，你根本无法用 MCU 控制 PGA113。**

**P30 — Gain Selection Bits + MUX Channel Selection（Table 5 + Table 6）**

- 位置：页面上半部分 Table 5（增益码表）、下半部分 Table 6（通道码表）

- 重要性：**极高**。

  - **Table 5**（Scope Gains）：G3~G0 对应的增益值 — 例如 `0000`=1, `0001`=2, `0010`=5, `0011`=10, `0100`=20, `0101`=50, `0110`=100, `0111`=200
  - **Table 6**（MUX 通道）：PGA113 只用 `0000`=VCAL/CH0, `0001`=CH1，其余标"X"不可用

  **这两张表 + P29 的命令格式 = 完整的 SPI 控制字。比赛时必须把它们抄到草稿纸上。**

**P33 — Gain Equations（Figure 69 + Figure 70）**

- 位置：Figure 69（基本增益模块配置）、Figure 70（VREF = AVDD/2 时的配置）

- 重要性：**极高**。

  - 基本公式：VOUT = G × VIN（当 VREF = GND）
  - 带虚拟地：VOUT = G × VIN − AVDD/2 × (G−1)（当 VREF = AVDD/2）
  - **注意**：G=1 时 VREF 引脚无影响（内部反馈电阻被短接）

  **这些公式决定了你如何设置输入偏置和输出范围。**

**P34 — Table 7: 内部 RF 和 RI 电阻值**

- 位置：整页一个表格
- 重要性：**中高**。给出了每个增益档位对应的内部反馈电阻 RF 和输入电阻 RI 的典型值（如 G=10 时 RF=29.25kΩ, RI=3.25kΩ）。比赛时一般不需要精确知道内部电阻值，但如果你需要做 Spice 仿真建模，这个表很有用。

**P41 — Power Supplies（第9.1.7节）**

- 位置：页面正文 + Figure 76

- 重要性：

  高

  。关键信息：

  - AVDD 和 DVDD 可以接同一电源，但**每个引脚必须单独接 0.1μF 陶瓷去耦电容**
  - 混合供电：AVDD=5V, DVDD=3V 时可直接对接 3V 逻辑的 MCU
  - **洞洞板上忘了去耦电容 = 自找振荡。**

**P42 — Typical Application Schematic（Figure 77）**

- 位置：页面上半部分
- 重要性：**极高**。这就是 PGA112/PGA113（VSSOP-10）的典型应用电路原理图，展示了所有外围连接：电源去耦、输入电路、VREF 接法、SPI 连线。**这是你画洞洞板接线图的"标准答案"。**

### 需要时查阅（比赛时按需翻阅即可）

**P10 — SPI 时序波形图**：P9 的配套图，写 SPI 代码时如果时序不对再回来看。

**P11-19 — Typical Characteristics 曲线图（共 9 页）**：

- 这些页面包含了几十个性能曲线图（失调电压分布、CMRR vs 频率、THD+Noise vs 频率/增益、PSRR、输出摆幅、增益 vs 频率等）

- 重要度

  ：中。比赛时一般不需要逐张看，但以下曲线比较有用：

  - **Figure 27-30（THD+Noise vs Frequency）**：如果你做信号调理且关心失真，需要看
  - **Figure 39-42（Output Voltage vs Load/Current）**：了解输出驱动能力
  - **增益-频率响应曲线**：了解高增益下带宽收窄程度

- **大部分曲线可以跳过**，除非你在调试阶段遇到具体问题（振荡、失真、带宽不够等）。

**P23-28 — SPI Daisy-Chain 详解**：

- PGA113 **不支持**独立的 DOUT 引脚，只能作为菊花链的"末端设备"（write-only）
- 比赛时如果只用单颗 PGA113，这 6 页**全部可以跳过**
- 如果需要多颗 PGA116/117 级联，才需要看

**P31-32 — Application Information 开头**：概述性文字和 Rail-to-Rail 输入级说明（Figure 66-68）。理解输入共模范围限制时有用。

**P35-40 — CAL 通道校准 + ADC 校准算法**：

- Table 8-11 和 Figure 73-74 详细描述了如何利用 CAL 通道做系统级 ADC 校准
- 比赛时如果你的系统需要高精度 ADC 采集，这部分是"加分项"
- 如果时间紧张，**可以先跳过**

**P43-46 — 典型应用：双极性输入缩放**：

- Figure 79-81 展示了如何将 ±5V/±10V 双极性信号缩放到单电源 ADC 可接受的范围内
- 比赛题目如果涉及双极性信号采集，这部分**非常有用**
- 否则可以跳过

**P47-48 — Layout Guidelines**：

- 关键建议：去耦电容紧贴引脚、VOUT 走线远离 MUX 高阻输入、用保护走线隔离输入通道
- **洞洞板焊接时的"经验法则"**，值得花 1 分钟扫一遍

## 三、总结：竞赛速查优先级

| 优先级      | 页码                               | 你要找什么                           |
| ----------- | ---------------------------------- | ------------------------------------ |
| **第 1 步** | P1                                 | 芯片是什么、能干什么                 |
| **第 2 步** | P4（上半）                         | 引脚怎么接                           |
| **第 3 步** | P5（上半）                         | 最大额定值（别烧芯片）               |
| **第 4 步** | P42                                | 典型应用电路（怎么接外围）           |
| **第 5 步** | P20                                | 内部架构（VREF 怎么用）              |
| **第 6 步** | P29-30                             | SPI 命令格式 + 增益码 + 通道码       |
| **第 7 步** | P33                                | 增益公式（计算输出电压范围）         |
| **第 8 步** | P21                                | 各增益下的带宽和建立时间             |
| **第 9 步** | P6-7                               | 关键电气参数（失调、带宽、输出摆幅） |
| **按需**    | P41, P47                           | 电源去耦 + 布局注意                  |
| **跳过**    | P2, P11-19(大部分), P23-28, P49-61 | 共约 35 页                           |

**核心结论**：这份 61 页手册中，真正需要你比赛时花精力看的只有约 **10-12 页**（约 20%），剩余 80% 要么是其他型号的专用信息、要么是封装物流信息、要么是调试阶段才需要的特性曲线。掌握这个"二八法则"，遇到类似的 TI PGA/运放/ADC 手册，你也可以按同样的思路快速定位：**首页概览 → 引脚图 → 绝对最大额定值 → 典型应用电路 → 接口/命令格式 → 关键电气参数**，其余按需翻阅。
