## 一、关键纠错：瞬态仿真时 Vin 到底是多少？

Vin 源标注了三组参数，但**瞬态仿真（TRAN）只认 PULSE 定义**：

```
Vin: PULSE(-20  20  0  100p  80u  160u)
          ↑    ↑              ↑    ↑
         低   高             脉宽  周期
         -20V +20V           80μs  160μs（50%占空比）
```

DC=2.5V 和 AC=0.1V 是给 **DC 工作点分析**和 **AC 小信号分析**用的，**在 TRAN 瞬态仿真中完全被 PULSE 覆盖**。

所以瞬态仿真时，Vin 就是 **±20V 的方波**，没有 2.5V 的事。
