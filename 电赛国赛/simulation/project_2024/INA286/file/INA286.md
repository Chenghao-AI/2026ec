在该工程的仿真中：TRAN 的含义

**TRAN** 是 **Transient Analysis（瞬态分析）** 的缩写，是 Spice 仿真三种分析模式之一。

------

### 这个 Vin 源标注了三种分析模式下的行为

| 仿真模式             | 参数     | 含义                                  |
| -------------------- | -------- | ------------------------------------- |
| **DC**（直流分析）   | DC = 0   | 做静态工作点分析时，Vin = **0V**      |
| **AC**（交流分析）   | AC = 1   | 做频率响应分析时，Vin 的幅度 = **1V** |
| **TRAN**（瞬态分析） | PULSE(…) | 做时域仿真时，Vin 是一个**方波脉冲**  |

你做的是**瞬态仿真**，所以 Vin 的值完全由 PULSE 定义。

------

### PULSE 参数逐个拆解

Spice 标准格式：`PULSE(V1 V2 TD TR TF PW PER)`

```
PULSE( -20   20   0   100p   100p   80u   160u )
         ↑    ↑   ↑    ↑      ↑      ↑     ↑
        低电平 高 延迟 上升   下降   脉宽   周期
```

| 参数           | 值    | 含义                                               |
| -------------- | ----- | -------------------------------------------------- |
| V1（低电平）   | -20V  | 方波"低"的时候 Vin = -20V                          |
| V2（高电平）   | +20V  | 方波"高"的时候 Vin = +20V                          |
| TD（延迟）     | 0     | 从 t=0 就开始跳变，无延迟                          |
| TR（上升时间） | 100ps | 从 -20V 升到 +20V 只需 100 皮秒（近似理想方波）    |
| TF（下降时间） | 100ps | 从 +20V 降到 -20V 只需 100 皮秒                    |
| PW（脉宽）     | 80μs  | 每个高电平持续 80 微秒                             |
| PER（周期）    | 160μs | 完整周期 160 微秒（50%占空比，对应频率 ≈ 6.25kHz） |

------

### 一句话总结

> **TRAN = PULSE(…)** 就是告诉仿真器："在时域仿真中，把我这个电源当成一个 ±20V 的方波发生器来驱动。"

所以你仿真出来看到 V(IN) - V(LOAD) 是一个 ±40mV 的方波，就是因为这个 ±20V 的方波输入驱动了 Rshunt+Rload 的回路。

### VSRC 的本质

**VSRC** 就是 Spice 里的通用电压源模型（Simple Voltage Source）。它的神奇之处在于——**一个元件可以同时配置三种分析模式下的行为**，仿真器在运行时自动"切换"：

| 你在仿真时选择的分析类型   | VSRC 自动使用哪个参数      |
| -------------------------- | -------------------------- |
| `.op` 或 `.dc`（直流分析） | 读取 **DC = 0**            |
| `.ac`（交流分析）          | 读取 **AC = 1**            |
| `.tran`（瞬态分析）        | 读取 **TRAN = PULSE(...)** |

------

### 为什么设计成这样？

如果不用 VSRC，你就需要：

- 做 DC 分析时放一个直流源
- 做 AC 分析时换成交流源
- 做瞬态分析时再换成脉冲源

有了 VSRC，**一个源填三个参数就够了**，仿真器根据你点击的分析类型自动选对应的那个。

------

### 所以你的电路图中

```
Vin
├── DC = 0       → 做直流分析时 Vin 输出 0V
├── AC = 1       → 做交流分析时 Vin 输出 1V 正弦激励
└── TRAN = PULSE → 做瞬态分析时 Vin 输出 ±20V 方波
```

你当前跑的是 `.tran` 瞬态仿真，所以 Vin 实际输出的是 **±20V 方波**，DC 和 AC 的参数被完全忽略。

------

### 比赛中怎么用？

比赛时你在洞洞板上搭电路，实际硬件只有一个物理电源。**仿真阶段用 VSRC 很方便**——同一个电路文件，改一下仿真类型就能做不同的分析，不需要反复改电路图。但记住：**硬件上你只需要按瞬态分析的工况来设计电源就行**（因为你最终验证的是时域波形）。
