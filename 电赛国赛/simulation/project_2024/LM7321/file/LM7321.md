## 二、逐页精析：看 / 查 / 跳 三级分类

### 🔴 必须赛前精读（比赛时大脑直接调用的信息）

**第 1 页 — Features（特色参数一览）**

- **为什么重要**：和之前一样，这是"芯片卖点 + 关键参数"的浓缩版。30 秒内判断"能不能用"。

- LM7321 关键参数

  ：

  - 供电电压：2.7~32 V（±1.35~±16 V）→ **高压运放，远超 OPA333 的 5.5 V 上限**
  - 输出电流：±125 mA → **大电流驱动能力，可以直驱 MOSFET/功率晶体管**
  - 增益带宽积：24 MHz → **比 OPA4322 还快 20%**
  - 压摆率：35 V/μs → **三款里最快，是 OPA4322 的 2.7 倍**
  - 无限容性负载容限 → **可以驱动任意大电容负载而不振荡，这是 LM7321 的独家杀手锏**
  - 输入共模电压范围：超出电源轨 0.1 V → Rail-to-Rail Input
  - 电压噪声密度：典型 12 nV/√Hz
  - 电流噪声密度：典型 1 pA/√Hz
  - 静态电流：典型 1.35 mA（每路）→ 和 OPA4322 同级
  - THD+N：典型 -113 dB → 低失真
  - CMRR：典型 77~125 dB（随供电电压变化）
  - AEC-Q100 Grade 1 汽车级认证 → 可靠性高

- **比赛策略**：背下这些数字。注意 LM7321 的定位是**"高压高速大电流全能运放"**——它不是精密运放（失调电压 0.35 mV，比 OPA333 大 35 倍），但它的速度、电流驱动能力和容性负载能力是三款中最强的。拿到新芯片先扫 Features，30 秒内判断是否满足系统需求。

**第 3 页 — Pin Configuration and Functions（引脚定义）**

- **为什么重要**：洞洞板搭电路，接错引脚 = 芯片烧毁。这是**最不能出错**的一页。
- **LM7321（5 脚 SOT-23/DBV 封装）**的引脚：
  - Pin 1：OUT（输出）
  - Pin 2：V-（负电源）
  - Pin 3：+IN（同相输入）
  - Pin 4：-IN（反相输入）
  - Pin 5：V+（正电源）
- **LM7321（8 脚 SOIC/D 封装）**：Pin 1=N/C, Pin 2=-IN, Pin 3=+IN, Pin 4=V-, Pin 5=N/C, Pin 6=OUT, Pin 7=V+, Pin 8=N/C
- **LM7322（8 脚 SOIC/DGK 封装）**：双运放版本，Pin 1=N/C, Pin 2=-IN(A), Pin 3=+IN(A), Pin 4=V-, Pin 5=N/C, Pin 6=OUT(A), Pin 7=V+, Pin 8=-IN(B)（还有 +IN(B)/OUT(B) 等）
- **比赛策略**：把这个引脚图截图存手机。注意 DBV 封装 Pin 1 是**输出**（和 OPA333 不同，和 OPA376 相同），引脚排列和 OPA333 完全不同！SOIC 封装有 N/C（No Connection）引脚，洞洞板不用管。

**第 4 页 — Absolute Maximum Ratings（绝对最大额定值）**

- **为什么重要**：超过这些值芯片会永久损坏。比赛时电源接反、电压超范围都会触发。

- LM7321 关键限值

  ：

  - 供电电压：0~33 V（绝对最大）→ **比 OPA333 的 ±6 V 高 5.5 倍**
  - 输入共模电压：(V-) - 0.5 V 到 (V+) + 0.5 V
  - 输入差分电压：±10 V → **差分耐压很高，可以承受较大的差分输入**
  - 输入电流：±10 mA（输入引脚有二极管钳位到电源轨）
  - 输出短路：连续短路（有保护）
  - 结温：150°C
  - 存储温度：-65~150°C
  - ESD：HBM ±2000 V, CDM ±1000 V

- **推荐工作条件**：供电 2.7~32 V，温度 -40~125°C

- **热信息**：RθJA — SOIC 133.5°C/W, SOT-23 185.4°C/W, VSSOP 169.6°C/W

- **比赛策略**：重点看"供电电压"和"输入差分电压"。LM7321 的差分耐压 ±10 V 很高，但输入共模范围仍然只超出电源轨 0.5 V。输出可以连续短路，但长时间短路会导致结温升高（需计算功耗）。

**第 5~6 页 — Electrical Characteristics（电气特性表）🏆 全书最重要的页面**

- **为什么重要**：这是**所有参数的权威数值表**，包含测试条件、最小/典型/最大值、单位。比赛设计时必须从这里取值做计算。

- 必须逐行看懂的参数字段

  （以 LM7321 为例）：

  - **VOS（失调电压）**：典型 ±0.35 mV，最大 ±5 mV（25°C），全温最大 ±6 mV → **比 OPA333 的 10 μV 大 35 倍，不是精密运放**
  - **TC VOS（失调电压温漂）**：典型 ±2.5 μV/°C → 比 OPA333 的 0.05 μV/°C 差 50 倍
  - **IB（输入偏置电流）**：典型 0.4 μA，最大 1 μA（25°C），全温最大 1.5 μA → **BJT 输入级（和 OPA333 的 pA 级、OPA4322 的 fA 级完全不是一个量级）**
  - **IOS（输入失调电流）**：典型 7 nA，最大 200 nA → 同样远大于 JFET/CMOS 输入运放
  - **CMRR（共模抑制比）**：典型 77~125 dB（随供电电压变化），最小 74~109 dB → 供电电压越高 CMRR 越高
  - **PSRR（电源抑制比）**：典型 104 dB（5~32V），最小 78 dB；低压下典型 74 dB → 高压供电时 PSRR 很好
  - **AVOL（开环增益）**：典型 80~87 dB，最小 62~75 dB → 和精密运放差一些
  - **VOUT（输出摆幅）**：距电源轨 50~160 mV（RL=10kΩ），50~280 mV（RL=2kΩ）→ Rail-to-Rail Output
  - **IOUT（输出电流）**：Vs=32V 时典型 ±125 mA，最小 ±40 mA；Vs=5V 时典型 ±85 mA → **大电流驱动能力**
  - **IS（静态电流）**：典型 1.35 mA（25°C），最大 1.93 mA；全温最大 2.23 mA → 和 OPA4322 同级
  - **SR（压摆率）**：典型 35 V/μs → **全系列最快**
  - **fu（单位增益频率）**：典型 11 MHz
  - **GBW（增益带宽积）**：典型 24 MHz → **全系列最快**
  - **en（电压噪声密度）**：典型 11.9 nV/√Hz
  - **in（电流噪声密度）**：典型 0.5 pA/√Hz → **BJT 输入级的特征噪声**
  - **THD+N（总谐波失真+噪声）**：典型 -113 dB
  - **CT Rej.（串扰抑制）**：典型 60 dB（LM7322 双运放）

- **测试条件**：TA = 25°C, RL = 10 kΩ 接 Vs/2, VCM = Vs/2, VOUT = Vs/2

- **比赛策略**：这个表要反复看。注意 LM7321 的 trade-off：**高速 + 大电流 + 高压 + 无限容性负载，代价是失调电压大（0.35 mV）、偏置电流大（0.4 μA）、不是精密运放**。和 OPA333/OPA376 的精密路线完全不同，和 OPA4322 的高速路线类似但电压/电流更高。

**第 17~20 页 — Detailed Description（详细原理说明）**

- 第 17 页（Overview + Functional Block Diagram）

  ：

  - LM732xx 是轨对轨输入输出放大器，35V/μs 压摆率 + 24 MHz GBW，每通道仅 1.35 mA 供电电流
  - 功能框图展示标准运放符号（+IN, -IN, OUT, V+, V-）

- 第 17 页（Output Short Circuit Current and Dissipation Issues）

  ：

  - 输出可以连续短路，但长时间短路会导致结温升高
  - 总功耗 = 静态功耗 + 直流负载功耗 + 交流负载功耗（PTOTAL = PQ + PDC + PAC）
  - **比赛策略**：洞洞板搭大电流电路时，注意 LM7321 的功耗计算。SOT-23 封装 RθJA = 185.4°C/W，散热不如 SOIC。

- 第 19 页（Driving Capacitive Loads）

  ：

  - LM732xx 可以驱动**无限容性负载**而不振荡（这是它的独家特性）
  - 相位裕度 vs 容性负载曲线（Figure 6-1）：增益为 +1 时，即使容性负载很大也能保持稳定
  - 串联隔离电阻可进一步改善稳定性，但会降低增益带宽积
  - **比赛策略**：这是 LM7321 最大的卖点——驱动长电缆、大电容负载（如 ADC 采样电容、TFT 缓冲器）时无需额外补偿。洞洞板上可以直接驱动容性负载而不用担心自激。

- 第 20 页（Electrical Overstress）

  ：

  - 输入/输出引脚有电流导向二极管连接到电源引脚
  - 背对背输入二极管保护输入晶体管免受大差分信号损伤
  - ESD 保护电路在正常工作时保持非激活状态
  - **比赛策略**：输入差分电压可达 ±10 V（绝对最大），但正常工作时仍需注意不要超过共模范围。输入过压时需串联电阻限流到 10 mA 以下。

```
  → 无限容性负载驱动能力（LM7321 的独家卖点）

第 6 步：看 Typical Characteristics（按需）
  → 带宽不够？→ 看 Gain-Bandwidth 图
  → 容性负载不稳定？→ 看 Phase Margin vs Capacitive Load 图（LM7321 几乎不担心）
  → 噪声太大？→ 看 Noise 图

第 7 步：看 Application 电路（选读）
  → 有没有类似你的应用场景的参考电路
```

## 五、LM7321 在比赛中的典型应用场景

基于 LM7321 的特性（高压 32V + 大电流 ±125mA + 24 MHz + 无限容性负载），它在比赛中最适合：

1. **驱动功率器件**：±125 mA 输出电流可以直接驱动 MOSFET/功率晶体管的栅极，这是 OPA333/OPA376/OPA4322 都做不到的（它们输出电流只有几 mA）
2. **高压信号处理**：供电最高 32 V，可以处理高压信号（如工业 4~20 mA 环路的高边检测、高压传感器信号调理）
3. **驱动容性负载**：无限容性负载容限，可以直驱长电缆、ADC 采样电容、TFT 缓冲器等，无需额外补偿电路
4. **高速大信号处理**：35 V/μs 压摆率 + 24 MHz 带宽，适合处理快速大信号（如脉冲整形、高速采样保持）
5. **电流检测**：手册明确推荐高边/低边电流检测应用，±125 mA 驱动能力可以直驱检测电阻和后续电路

## 六、与前几款芯片分析的共性策略总结

四本手册虽然芯片特性完全不同，但**阅读策略完全一致**：

1. **第 1 页 Features** → 30 秒判断芯片定位
2. **引脚图** → 绝对不能接错（注意 LM7321 的 Pin 1 是输出，和 OPA333 不同！）
3. **Absolute Maximum Ratings** → 防止烧毁（LM7321 耐压高，但别超 33V）
4. **Electrical Characteristics** → 设计取值的唯一权威来源（注意 LM7321 是 BJT 输入，IB 是 μA 级）
5. **Detailed Description** → 理解架构和特殊限制（LM7321 的无限容性负载 + 功耗计算）
6. **Typical Characteristics** → 按需查图
7. **Application** → 找参考电路
8. **第 26 页以后全部跳过** → 封装机械图与洞洞板无关

**核心原则**：LM7321 手册第 1~5 页 + 第 17~20 页是"核心区"。掌握这个阅读策略后，遇到任何 TI 运放手册都可以 5 分钟内定位关键信息。

**LM7321 的赛场定位一句话总结**：它是四款芯片中的"大力士"——高压（32 V）+ 大电流（±125 mA）+ 高速（24 MHz / 35 V/μs）+ 无限容性负载，但失调电压大（350 μV）、偏置电流大（0.4 μA），**不适合精密直流放大，适合功率驱动和高压高速场景**。当题目要求"驱动功率管""高压信号处理""大电流输出"时，LM7321 是唯一选择。



这是 **LM7321 的 DGK 封装（8 脚）**，内部有 **两个运放 A 和 B**。如果你只用 A（Pin 1/2/3），那 B 的三个引脚（Pin 5/6/7）必须妥善处理，否则闲置运放会振荡，通过电源耦合干扰 A。

------

## 推荐方案：单位增益缓冲（最稳妥）

```
        V⁻ (GND)
         │
         │
  +IN B ─┤  (Pin 5 接 GND 或 V⁻/2)
         │
  -IN B ─┤  (Pin 6)
   ▲     │
   │     └──┤ OUT B (Pin 7)
   └────────┘
    用导线短接
```

**具体接法：**

| 引脚           | 功能     | 处理方式                                |
| -------------- | -------- | --------------------------------------- |
| Pin 5（+IN B） | 同相输入 | 接 **GND**（单电源）或 **V⁻**（双电源） |
| Pin 6（-IN B） | 反相输入 | 与 Pin 7 **短接**（构成电压跟随器）     |
| Pin 7（OUT B） | 输出     | 与 Pin 6 **短接**，**不接任何其他负载** |

**原理**：运放 B 工作在负反馈状态，输出被锁在一个确定电平，既不会饱和也不会振荡，对电源的干扰最小。

------

## 不推荐的方案及原因

| 错误做法                     | 后果                                                         |
| ---------------------------- | ------------------------------------------------------------ |
| Pin 5/6/7 全部悬空           | 输入浮空 → 极易拾取噪声 → **自激振荡**，通过 V⁺/V⁻ 耦合干扰运放 A |
| Pin 5 接 V⁺、Pin 6 接 GND    | 巨大差分输入 → 输出饱和到 V⁻ → 持续大电流 → **功耗异常 + 可能振荡** |
| Pin 7（输出）直接接 GND      | 运放拼命驱动但被强制拉低 → 输出级大电流 → 发热 + 干扰        |
| Pin 5/6 都接 GND，Pin 7 悬空 | 比全悬空好一点，但开环状态仍有振荡风险（不推荐）             |

------

## 比赛实操总结

一句话：**输出接反相输入，同相输入接中间电平（GND 或 V⁻）**。

洞洞板上只需跳一根线（Pin 6 → Pin 7），再把 Pin 5 接到你已有的 GND 即可，零额外元件。
