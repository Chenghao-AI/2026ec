## 零、先搞清楚这份手册的"坑"——它是一个**家族手册**

这份手册与 UA741 那份的最大不同在于：**它不是一个芯片，而是一整个家族**：

| 命名规则 | 含义   | 通道数 |
| -------- | ------ | ------ |
| TL081x   | 单通道 | 1      |
| TL082x   | 双通道 | 2      |
| TL084x   | 四通道 | 4      |

后缀字母区分**精度等级**和**代际**：

| 后缀        | 代际                 | 关键区别                                      |
| ----------- | -------------------- | --------------------------------------------- |
| C / AC / BC | 老款（经典 TL08x）   | SR=13V/μs(typ)，VOS=3mV(typ)，供电 ±15V       |
| **H**       | **新一代（TL08xH）** | **SR=20V/μs(typ)，VOS=1mV(typ)，供电最高40V** |

> **比赛时第一件事**：看芯片丝印上的完整料号，确认你拿到的是哪个后缀（C? AC? BC? H?），然后直接跳到对应的参数表。

手册 78 页之所以这么长，就是因为要覆盖 3 个通道数 × 4-5 个精度等级 × 十几种封装。**大部分内容你不需要看**。

## 一、整份手册的结构总览与重要性分级

### ★★★ 必读——比赛时第一时间要看的

**第 3-5 页 — 第 4 节 "Pin Configuration and Functions"（引脚配置）**

这份手册引脚图非常多，因为家族成员太多。你只需要找你那个料号对应的图：

- **TL081 单通道** → **Figure 4-1**（5 引脚 SOT-23/SC70）和 **Figure 4-3**（8 引脚 SOIC/PDIP/SO）
- **TL082 双通道** → **Figure 4-5**（8 引脚各种封装）
- **TL084 四通道** → **Figure 4-7**（14 引脚各种封装）
- **Table 4-2**（第 8 页）：引脚功能总表，逐脚说明

8 引脚 PDIP/SOIC 的 TL081 引脚排列（你最可能在洞洞板上用的封装）：

| 引脚号 | 功能                  |
| ------ | --------------------- |
| 1      | OFFSET N1（失调调零） |
| 2      | IN-（反相输入）       |
| 3      | IN+（同相输入）       |
| 4      | VCC-（负电源）        |
| 5      | OFFSET N2（失调调零） |
| 6      | OUTPUT（输出）        |
| 7      | VCC+（正电源）        |
| 8      | NC（空脚）            |

- **比赛价值**：与 UA741 的 8 引脚排列**非常相似但不完全一样**！注意 TL081 的引脚 1 和 5 是 OFFSET N1/N2（失调调零端），而不是 NC。UA741 的引脚 1 和 5 也是 OFFSET NULL，但具体内部电路不同。

**第 9 页 — 第 5.1 节 "Absolute Maximum Ratings"（绝对最大额定值）**

| 参数         | 极限值                             | 备注                       |
| ------------ | ---------------------------------- | -------------------------- |
| 供电电压 V_S | 42V（多数封装）/ 36V（NS/PS 封装） | 双电源即 ±21V / ±18V       |
| 共模输入电压 | (V-) - 0.5 到 (V+) + 0.5           | 几乎贴着电源轨             |
| 差模输入电压 | V_S + 0.2 V                        | 基本等于供电电压           |
| 输入电流     | ±10 mA                             | 输入信号超电源轨时必须限流 |
| 输出短路     | **Continuous（持续）**             | 好消息，短路不烧           |
| 工作温度 T_A | -55°C 到 150°C                     |                            |

- **比赛价值**：比 UA741 的 ±18V 极限（36V）更宽，多数封装可达 **42V（±21V）**。但**NS 和 PS 封装只有 36V（±18V）**——务必确认封装类型！
- **特别注意**：输入引脚有二极管钳位到电源轨，输入信号超过电源轨 0.5V 以上时必须限流到 10mA 以下，否则烧毁。

**第 12-13 页 — 第 5.7 节 "Electrical Characteristics: TL08xH"（H 系列电气特性）★★★ 最核心**

如果你拿到的是 **TL08xH** 系列，这两页就是整份手册信息密度最高的地方（测试条件：V_S = 4.5V 至 40V，T_A = 25°C，R_L = 10kΩ）：

| 参数                      | 典型值    | 最大值  | 含义与比赛意义                                |
| ------------------------- | --------- | ------- | --------------------------------------------- |
| V_OS（输入失调电压）      | ±1 mV     | ±4 mV   | 比 UA741 的 0.3mV 稍差，但够用                |
| dV_OS/dT（失调温漂）      | ±2 μV/°C  | —       | 比 UA741 好得多                               |
| I_B（输入偏置电流）       | **±1 pA** | ±120 pA | **JFET 输入！比 UA741 的 10nA 低 4 个数量级** |
| I_OS（输入失调电流）      | ±0.5 pA   | ±120 pA | 极高阻抗源也不怕                              |
| E_N（输入噪声密度）       | 37 nV/√Hz | —       | 1kHz 处，中等水平                             |
| 输出摆幅（正轨 headroom） | 115 mV    | 210 mV  | R_L=10kΩ 时距正轨仅 115mV，接近轨到轨         |
| 输出摆幅（负轨 headroom） | 105 mV    | 215 mV  | R_L=10kΩ 时距负轨仅 105mV                     |
| I_SC（输出短路电流）      | ±26 mA    | —       | 驱动能力一般                                  |
| C_LOAD（容性负载）        | 300 pF    | —       | 超过可能振铃/不稳定                           |
| I_Q（静态电流）           | 940 μA    | 1125 μA | 每通道不到 1mA，比 UA741 省很多               |
| 开启时间                  | 60 μs     | —       | 上电到稳定工作只需 60μs                       |

**第 14-16 页 — 第 5.8/5.9 节 "Electrical Characteristics: TL08xC/AC/BC"（老款 C 系列电气特性）**

如果你拿到的是老款 **TL08xC / TL08xAC / TL08xBC**，看这两页：

| 参数            | TL08xC           | TL08xAC          | TL08xBC          |
| --------------- | ---------------- | ---------------- | ---------------- |
| V_OS（失调）    | 3 mV (max 10)    | 3 mV (max 6)     | 2 mV (max 3)     |
| I_B（偏置电流） | 50 pA (typ)      | 50 pA (typ)      | 50 pA (typ)      |
| SR（压摆率）    | 13 V/μs (typ)    | 13 V/μs (typ)    | 13 V/μs (typ)    |
| I_Q（静态电流） | 1.4 mA (typ)     | 1.4 mA (typ)     | 1.4 mA (typ)     |
| 噪声            | 18 nV/√Hz @ 1kHz | 18 nV/√Hz @ 1kHz | 18 nV/√Hz @ 1kHz |

- 第 16 页 5.9 节是 AC 参数

  ，所有老款共用一张表，核心参数：

  - **Slew Rate（压摆率）**：最低 8 V/μs，典型 **13 V/μs**（比 UA741 的 0.5V/μs 快 26 倍！）
  - **噪声**：18 nV/√Hz @ 1kHz（老款比 H 款更低！）
  - **相位裕度**：56°（G=+1，R_L=10kΩ，C_L=20pF）
  - **建立时间**：0.1% 精度约 0.1μs

**第 26 页 — 第 8.3 节 "Power Supply Recommendations"（电源建议）**

- 供电范围：±2.25V 到 ±20V（H 系列）/ ±15V（C 系列）
- **必须在电源引脚附近放 0.1μF 陶瓷去耦电容**
- **警告**：单电源超过 36V 或双电源超过 ±18V 会永久损坏
- 支持单电源和双电源两种工作模式
- **比赛价值**：与 UA741 相同的操作——VCC+ 和 VCC- 引脚各并一个 0.1μF 瓷片电容到地。

## 二、TL081 vs UA741 核心参数速查对比

| 参数                  | UA741         | TL081 (C 系列) | TL081H (新一代)   |
| --------------------- | ------------- | -------------- | ----------------- |
| **输入类型**          | BJT           | **JFET**       | **JFET**          |
| **输入偏置电流 I_B**  | 80 nA (max)   | 50 pA (typ)    | **1 pA (typ)**    |
| **输入失调电压 V_OS** | 0.3 mV (typ)  | 3 mV (typ)     | **1 mV (typ)**    |
| **压摆率 SR**         | 0.5 V/μs      | 13 V/μs        | **20 V/μs**       |
| **供电电压**          | ±5V~±15V      | ±15V (max)     | **±2.25V~±20V**   |
| **输出短路**          | 持续          | 持续           | 持续              |
| **静态电流**          | ~1.7 mA       | 1.4 mA (typ)   | **0.94 mA (typ)** |
| **噪声 @ 1kHz**       | —             | 18 nV/√Hz      | 37 nV/√Hz         |
| **输出摆幅**          | ±14V (RL≥10k) | ±13.5V (typ)   | 距轨 ~115mV       |

**一句话总结**：TL081 是 UA741 的"全面升级版"——压摆率快 26-40 倍、偏置电流低 4-5 个数量级、功耗更低、供电范围更宽。唯一略差的是 H 版噪声稍大，但 C 版噪声反而比 UA741 还好。

## 三、比赛时的"闪电检索法"（TL081 专用版）

拿到这份手册后，按以下顺序定位（预计 **2-3 分钟**内搞定）：

1. **确认你的料号后缀**（看芯片丝印）→ C? AC? BC? H?

2. **找引脚图**（第 3-5 页）→ 只找你那个通道数对应的图

3. **找 Absolute Maximum Ratings**（第 9 页）→ 确认供电极限

4. 找 Electrical Characteristics

   ：

   - TL08x**H** → 第 12-13 页
   - TL08x**C/AC/BC** → 第 14-16 页
   - 重点看：V_OS、I_B、SR、输出摆幅、I_Q

5. **找 Power Supply Recommendations**（第 26 页）→ 去耦电容要求

6. **按需查**：典型特性曲线（第 17-22 页）、应用电路（第 25-27 页）

7. **第 28 页之后全部跳过**（38 页封装图 + 8 页行政/修订/订购信息）

**一句话口诀**：**料号 → 引脚 → 极限 → 参数表（H 看 12 页，C 看 14 页）→ 电源 → 按需深入 → 28 页后全扔**。
