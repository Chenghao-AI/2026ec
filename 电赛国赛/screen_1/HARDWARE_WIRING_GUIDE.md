# MSP-LITO-G3507-EVM 模块接线说明

## 1. 文档用途

本文档记录 `Electronic Competition` 工程当前已验证的硬件接线，用于赛前复查和赛场快速复现。

当前模块：

1. LCDWIKI MSP4020 4.0 寸 ST7796S SPI 屏幕，480×320，无触摸；
2. HW-834 4×4 无源矩阵键盘。

对应开发板：

```text
MSP-LITO-G3507-EVM
MCU: MSPM0G3507
GPIO 逻辑电平: 3.3 V
```

---

## 2. 上电前总体原则

1. 插拔任何信号线前，先断开开发板和屏幕供电。
2. 屏幕和开发板必须共地：屏幕 `GND` 必须连接开发板 `GND`。
3. MSPM0G3507 GPIO 是 3.3 V 逻辑，不要向 GPIO 输入 5 V 电平。
4. 屏幕电源线与地线尽量短且牢固；SPI 时钟和数据线避免使用过长、松动的杜邦线。
5. 不要仅根据杜邦线颜色接线，应逐根核对模块丝印和开发板 GPIO 丝印。

## 3. ST7796S SPI 屏幕接线

### 3.1 已验证的完整接线表

| 屏幕引脚        | 连接到       | 方向（相对 MCU） | 作用                      | 是否必接 |
| ----------- | --------- | ---------- | ----------------------- | ---- |
| `VCC`       | 开发板 `3V3` | 电源         | 为屏幕模块供电                 | 是    |
| `GND`       | 开发板 `GND` | 电源参考       | 与 MCU 共地                | 是    |
| `CS`        | `PB6`     | MCU 输出     | LCD 片选，低电平有效            | 是    |
| `RESET`     | `PB16`    | MCU 输出     | LCD 硬件复位，低电平复位          | 是    |
| `DC/RS`     | `PB15`    | MCU 输出     | 区分 SPI 命令和数据            | 是    |
| `SDI(MOSI)` | `PB8`     | MCU 输出     | SPI1 写数据线，向屏幕发送命令和像素    | 是    |
| `SCK`       | `PB9`     | MCU 输出     | SPI1 时钟                 | 是    |
| `LED`       | 开发板 `3V3` | 背光供电/控制    | 高电平点亮背光，当前为常亮           | 是    |
| `SDO(MISO)` | 不连接       | 屏幕输出       | 用于 MCU 读取 LCD 数据，当前驱动仅写 | 否    |
| `T_CLK`     | 不连接       | 触摸信号       | XPT2046 触摸 SPI 时钟       | 否    |
| `T_CS`      | 不连接       | 触摸信号       | XPT2046 触摸片选            | 否    |
| `T_DIN`     | 不连接       | 触摸信号       | XPT2046 触摸 SPI 输入       | 否    |
| `T_DO`      | 不连接       | 触摸信号       | XPT2046 触摸 SPI 输出       | 否    |
| `T_IRQ`     | 不连接       | 触摸信号       | XPT2046 触摸中断            | 否    |

当前屏幕为无触摸型 MSP4020，所有 `T_*` 引脚均不需要连接。

### 3.2 屏幕最小必需接线

```text
ST7796S 屏幕                MSP-LITO-G3507-EVM

VCC       ─────────────────── 3V3
GND       ─────────────────── GND
CS        ─────────────────── PB6
RESET     ─────────────────── PB16
DC/RS     ─────────────────── PB15
SDI(MOSI) ─────────────────── PB8
SCK       ─────────────────── PB9
LED       ─────────────────── 3V3
```

### 3.3 各信号的工作过程

#### `CS` — 片选

- 连接 `PB6`。
- 平时为高电平，屏幕不接收当前 SPI 传输。
- 写命令或像素前拉低，写完后拉高。
- 当多个 SPI 设备共用 MOSI/SCK 时，每个设备必须有独立 CS。

#### `RESET` — 屏幕复位

- 连接 `PB16`。
- 程序开机时先拉低约 100 ms，再拉高。
- 如果此线断开，屏幕可能背光亮但没有正常图像。

#### `DC/RS` — 命令/数据选择

- 连接 `PB15`。
- 低电平：MOSI 上的字节是 ST7796S 命令。
- 高电平：MOSI 上的字节是参数或像素数据。
- 如果该线接错，通常会出现白屏、花屏或完全无法初始化。

#### `SDI(MOSI)` — SPI 写数据

- 连接 `PB8`，对应工程中的 `SPI1 PICO/MOSI`。
- 传送屏幕寄存器命令、参数和 RGB565 像素数据。
- 不要误接到 `SDO(MISO)`。

#### `SCK` — SPI 时钟

- 连接 `PB9`。
- 当前 SysConfig 中使用 SPI1、Mode 0、8 bit、MSB first、约 4 MHz。
- 花屏或不稳定时，除了电源外，优先检查该线是否过长或接触不良。

#### `LED` — 背光

- 当前直接连接 `3V3`，上电后常亮。
- 屏幕有图像数据但 `LED` 未上电时，肉眼可能几乎看不到显示内容。
- 如果未来需要软件调光，应通过合适的三极管/MOSFET 驱动背光，不建议直接让 MCU GPIO 承担背光电流。

### 3.4 屏幕供电说明

LCDWIKI 资料标明该模块 `VCC` 支持 3.3 V～5 V，无触摸 MSP4020 标称功耗约 0.93 W。当前实物已经在开发板 3.3 V 供电下正常显示 UI，因此可保留该接法。

如果赛场重新搭建时出现以下情况，先检查供电能力：

- 背光闪烁；
- 开发板反复复位；
- 屏幕偶发白屏或花屏；
- 一刷新大面积图像就不稳定。

屏幕改用独立电源时，仍必须将独立电源 GND 与开发板 GND 连在一起。

LCDWIKI 原始接口资料：

```text

```

## 4. HW-834 4×4 矩阵键盘接线

### 4.1 键盘特性

该键盘是无源机械开关矩阵：

- 没有 `VCC` 引脚；
- 没有 `GND` 引脚；
- 只需要 8 根行列信号线；
- 按下某个按键时，只是将对应的两根矩阵线导通。

不要将键盘的任何 `C*` 或 `R*` 引脚直接连接 3.3 V 或 GND。

### 4.2 已实测确认的最终接线

| 键盘 PCB 丝印 | 开发板 GPIO | SysConfig 软件名      | GPIO 方向 | 对应实体键组          |
| --------- | -------- | ------------------ | ------- | --------------- |
| `C4`      | `PA8`    | `KEYPAD_COLS_COL1` | 输出      | S1、S5、S9、S13    |
| `C3`      | `PA9`    | `KEYPAD_COLS_COL2` | 输出      | S2、S6、S10、S14   |
| `C2`      | `PA12`   | `KEYPAD_COLS_COL3` | 输出      | S3、S7、S11、S15   |
| `C1`      | `PA13`   | `KEYPAD_COLS_COL4` | 输出      | S4、S8、S12、S16   |
| `R4`      | `PA17`   | `KEYPAD_ROWS_ROW1` | 输入，内部上拉 | S1、S2、S3、S4     |
| `R3`      | `PA16`   | `KEYPAD_ROWS_ROW2` | 输入，内部上拉 | S5、S6、S7、S8     |
| `R2`      | `PA15`   | `KEYPAD_ROWS_ROW3` | 输入，内部上拉 | S9、S10、S11、S12  |
| `R1`      | `PA14`   | `KEYPAD_ROWS_ROW4` | 输入，内部上拉 | S13、S14、S15、S16 |

注意：软件中的 `COL1/ROW1` 是扫描逻辑名称，不是 HW-834 PCB 上的原始 `C1/R1` 丝印。上表是为了让实体 S1～S16 与程序返回值 1～16 一一对应而重新排列的接法。

### 4.3 按照实物照片方向的速查顺序

键盘正面朝上、按键丝印可正常阅读、排针位于下方时，排针从左到右为：

```text
键盘丝印:  C4    C3    C2    C1    R1    R2    R3    R4
开发板:      PA8   PA9   PA12  PA13  PA14  PA15  PA16  PA17
```

可直接记忆为：

```text
键盘排针从左到右
        ↓
PA8, PA9, PA12, PA13, PA14, PA15, PA16, PA17
```

### 4.4 键盘扫描原理

#### PA8、PA9、PA12、PA13 — 列扫描输出

- 空闲时全部保持高电平。
- 扫描时每次只将其中一根拉低。
- 通过其中哪一根被拉低，确定按键编号的列位置。

#### PA17、PA16、PA15、PA14 — 带上拉的行输入

- 未按键时，内部上拉使输入保持高电平。
- 按下按键后，当前被拉低的扫描线通过按键传到对应输入，该输入被读为低电平。
- 程序结合当前扫描线和读到的输入线，返回 1～16 的键值。

### 4.5 实体键与程序键值

按上述接线时：

| 实体按键   | `Keypad_GetPress()` 返回值 | 当前 UI 功能        |
| ------ | -----------------------:| --------------- |
| S1     | 1                       | 显示频谱仪 UI        |
| S2     | 2                       | 显示周期信号 UI       |
| S3     | 3                       | 已可识别，暂未绑定 UI 事件 |
| S4     | 4                       | 已可识别，暂未绑定 UI 事件 |
| S5～S16 | 5～16                    | 已可识别，暂未绑定 UI 事件 |

## 6. 赛场快速接线顺序

### 第一步：保持断电

- 拔掉调试器/USB 供电。
- 如果使用独立屏幕供电，也先关闭。

### 第二步：先接屏幕供电

```text
VCC → 3V3
GND → GND
LED → 3V3
```

用万用表确认 `3V3` 与 `GND` 之间没有短路。

### 第三步：接屏幕控制和 SPI

```text
CS        → PB6
RESET     → PB16
DC/RS     → PB15
SDI(MOSI) → PB8
SCK       → PB9
```

`SDO(MISO)` 和所有 `T_*` 保持悬空。

### 第四步：按排针顺序接键盘

```text
C4→PA8, C3→PA9, C2→PA12, C1→PA13,
R1→PA14, R2→PA15, R3→PA16, R4→PA17
```

### 第五步：逐根复查

- 屏幕 VCC 与 GND 未接反；
- 屏幕 SDI 未误接到 SDO；
- PB15 接 DC，PB16 接 RESET；
- 键盘从左到右的 GPIO 为 `PA8, PA9, PA12, PA13, PA14, PA15, PA16, PA17`；
- 没有将键盘的任何线接入电源或地。

### 第六步：上电验证

1. 屏幕背光点亮；
2. 等待初始 UI 出现；
3. 按 S1，应显示频谱仪 UI；
4. 按 S2，应显示周期信号 UI。

## 7. 故障速查

### 7.1 屏幕背光不亮

优先检查：

1. `VCC → 3V3`；
2. `GND → GND`；
3. `LED → 3V3`；
4. 开发板 3.3 V 是否存在。

### 7.2 背光亮，但一直白屏

优先检查：

```text
RESET → PB16
CS    → PB6
DC    → PB15
SDI   → PB8
SCK   → PB9
```

确认 SDI 与 SDO 没有接反。

### 7.3 屏幕有图像，但花屏或闪烁

- 检查供电电压和供电电流；
- 缩短 MOSI/SCK/GND 连线；
- 检查 GND 接触；
- 检查杜邦线内部是否断路。

### 7.4 键盘完全无反应

- 检查 8 根线是否全部接通；
- 检查 `PA8/PA9/PA12/PA13` 是否接到 PCB `C4/C3/C2/C1`；
- 检查 `PA17/PA16/PA15/PA14` 是否接到 PCB `R4/R3/R2/R1`；
- 不要为无源键盘另外接 VCC/GND。

### 7.5 按键有反应，但编号不对

按下列顺序重新核对：

```text
PCB:  C4    C3    C2    C1    R1    R2    R3    R4
MCU:  PA8   PA9   PA12  PA13  PA14  PA15  PA16  PA17
```

只有一排按键或一列按键失效时，通常是其中一根线断路或松动。
