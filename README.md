## 一、校赛：简易频谱分析仪（B 题）

**任务**：设计制作超外差结构的简易频谱仪，本振使用锁相环电路。输入 80–100 MHz、有效值 1 mV（−47 dBm）信号，测量显示频谱分量的频率与功率（dBm），频率误差 ≤ 0.01%，功率误差 ≤ 1 dB；提高部分要求扫频步进 100 kHz、测量调幅波频谱与调幅指数。

**系统方案（超外差架构）**：

```
输入 80–100MHz → SPF5189 低噪声放大（NF≈0.8dB，增益≈16dB）
              → PE4302 数控衰减器（6bit，0.5dB 步进，0–31.5dB，程控）
              → AD831 混频器 ← ADF4351 PLL 本振（90–110MHz，步进 100kHz，扫频）
              → 10.7MHz 晶体中频滤波 → OPA847 中频放大（GBW 3.9GHz）
              → AD8307 对数检波（输出直接正比 dBm，动态范围 92dB）
              → STM32F407ZET6 板载 12-bit ADC 采集
              → FFT 处理 + ST7796 3.5" TFT（320×480，FSMC 驱动）频谱显示
```

- 主控选型论证：对比 STM32F407ZET6 / STM32F405RGT6 / TI TMS320F28379D，选定 F407（Cortex-M4 + FPU + DSP 指令，168 MHz，可跑 1024 点 FFT，FSMC 直驱 TFT）。
- 本振链路：ADF4351（VCO 覆盖 35 MHz–4.4 GHz）+ PE4302 幅度程控（50–200 mVpp 可调，误差 < 10%）。
- **实测**：本振幅度误差 ≤ 2.64%，扫频频率误差 0%，频谱测量频率误差 ≈ 0%、功率误差 ≤ 1 dB，全部达标。

**我的贡献**：负责屏幕显示模块（ST7796 驱动、FSMC 接口、频谱/光标 UI 绘制）与设计报告撰写。

> 详细资料见 `电赛校赛/`：赛题 PDF、B01 组设计报告、屏幕驱动工程（`屏幕终版/`）。

## 二、省赛：周期信号测量分析装置（G 题）

**任务**：测量 10 kHz–500 kHz 周期信号的时域参数（峰峰值、真有效值、基频）与频域频谱，频率分辨率 ≤ 500 Hz，基频误差 ≤ 1 kHz，幅值误差 ≤ 5 mV，并抑制 1 MHz 单频强干扰，全部任务 2 秒内完成。

**方案论证**：采用**两套方案交叉验证**——

1. 模拟超外差方案：AD9959 DDS 扫频本振 + 10.7 MHz 晶体滤波 + 对数检波，先测频域再 IFFT 合成时域；
2. **FPGA 数字方案**（最终选定）：无源前置滤波 + ADC 直接采集时域波形，FPGA 内部 FFT 得频域。

选择理由：模拟链路存在非线性失真与多级误差累积，时域参数需间接推导；FPGA 方案数据路径直接、误差来源单一，且并行架构使采集/滤波/FFT 同时进行，硬件级时序控制保证采样等间隔，是 500 Hz 分辨率与 2 s 时限的根本保证。

**FPGA 数字链路（我负责的部分）**——平台 Xilinx Zynq-7000 XC7Z020：

```
AD9226（12-bit, 4 MSPS，MMCM 50M→8M→2分频→4M 采样时钟，ODDR 驱动）
→ AdcChaCapture：8 拍 IDDR 对齐 + 偏移二进制 MSB 取反转补码
→ PreMul_Hann：8192 项汉宁窗（BRAM 存 12-bit Q0.12 系数，3 级流水乘法），泄漏 ≤ −31 dB
→ FrameBuf：8192×16 BRAM 乒乓缓冲，AXI-Stream 推入
→ Xilinx FFT IP v9.1：8192 点 Pipelined Streaming，16-bit 定点 Scaled
→ CORDIC IP v6.0（Translate 模式，直连 FFT 32-bit Re/Im 总线）求模 |X[k]|
→ Δf = 4MHz/8192 = 488.28 Hz < 500 Hz，基频误差 ±244 Hz < 1 kHz
→ spectrum_buffer（5–550 kHz，1116 点）+ waveform_capture（32768 深环形 BRAM，实时 Vpp/Vrms）
```

**跨芯片协作**：FPGA 按 `AA 55 | TYPE | SEQ | LEN | Payload | CRC16` 帧格式（CRC-16/CCITT-FALSE，ACK 超时自动重发 3 次）经 UART 460800-8-N-1 上传至 STM32F407；STM32 用 DMA+空闲中断+状态机解析，经 7×30 双线性校准表修正前端衰减，提取基波与整数倍谐波后驱动 TJC 串口屏分页显示时域波形与频谱柱。**从按下"开始测量"到屏幕出图全流程约 80 ms**（题目限时 2 s）。

**开发流程**：Chisel（Scala）在 WSL/Linux 端编写 → Verilator 仿真（6 组功能测试 + 5 项回归）→ 生成 Verilog 同步至 Windows 端 → Vivado 综合/布局布线（0 Error、0 Warning，全局WNS =28.172ns）→ ILA 上板调试 → MATLAB 离线验证。

**实测**（5 组含干扰的合成信号）：峰峰值/真有效值误差 ≤ 2.64%，频率分量误差 ≤ 0.2 kHz，幅值误差 ≤ 5 mV，干扰识别与抑制正确。

**我的贡献**：独立负责 FPGA 全部数字链路——ADC 接口时序、汉宁窗流水线、FFT/CORDIC IP 集成与跨时钟域设计、帧协议引擎，以及 Chisel→Verilator→Vivado 的完整开发验证流程。

> 详细资料见 `电赛省赛/`：省赛设计报告 `1195_s.pdf`、G 题原文、FPGA 工程与设计文档（电赛省赛\FPGA_windows\Vivado\verliog\A0_1）。

## 三、国赛：电路网络特性测量装置（B 题，全国三等奖）

**任务**：设计制作电路网络（RLC）特性测量装置——产生频率/幅度程控的正弦激励注入被测网络，**发射端与接收端仅通过可见光通信**；接收端屏幕呈现被测网络的**幅频响应、相频响应曲线**，窄脉冲模式下呈现**单位脉冲响应**，并输出与激励同频、Vpp > 3 V 的信号。

**系统方案**：

```
【发射端】
AD9850 DDS（单片机发控制字程控频率）
+ LM7321 / TLV9362 / TPL0401A（I2C 数字电位器）联合幅控电路（程控幅度）
→ 输出正弦激励（预留接口接入被测 RLC 网络）
→ 同路驱动 LED 发射自定义光强，以可见光通信（VLC）传输
   相位/频率/幅度信息 + 高精度时钟基准与相位参考码（消除链路时延与抖动）

【接收端】
光电二极管 + 运放放大 → 板载 ADC → 解析出发射信号参数（VLC 链路）
被测网络输出信号（加直流偏置后）→ 板载 ADC
→ 扫频模式：绘制幅频/相频响应曲线（谐振峰、相位跃变清晰可见）
→ 窄脉冲模式：IFFT 从频域数据重构单位脉冲响应（时域瞬态/阻尼特征）
→ 可输出与激励同频、Vpp > 3V 的信号
```

- 主控：TI MSPM0G3507（CCS Theia 开发），ST7796 屏 + 4×4 矩阵键盘 UI；
- 仿真验证：Spice For TI和Filter solution对幅控电路与接收端无源带通滤波器做仿真闭环；
- 仪器：RIGOL DP832 电源、DS2072 示波器、DG1022U 信号发生器。

**实测**：VLC 链路传输实时、误码率低；发射信号频率/幅度程控误差小（如 10 kHz 设定点实测 10.006 kHz / 1.506 V）；幅频曲线谐振峰值、相频曲线相位跃变、单位脉冲响应的瞬态振荡与阻尼特征均较好呈现，实测与理论仿真误差不大。

**我的贡献**：负责**硬件电路仿真**——用 Spice For TI和Filter solution 搭建并验证 LM7321+TLV9362+TPL0401A 联合幅控电路与接收端无源带通滤波器，在实物制作前确认增益、带宽、偏置与稳定性指标，为最终方案定型提供依据。

> 国赛设计报告见 `电赛国赛/B39-089.docx`；MSPM0 显示/键盘工程见 `电赛国赛/screen_1/`，无源滤波器电路图见“电赛国赛\RLC”，。
